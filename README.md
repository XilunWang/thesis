## 2. 当前BLL实际做什么

模型仍是原版Mask2Former，没有MFRM、DSGAT或独立边界预测头。BLL只在训练中增加一项损失，推理结构不变。

1. 复用原模型最后一层的query与GT匹配。
2. 将增强后GT缩到mask网格：4×4内只要有前景，该格就标为前景；有效边缘半格保留，纯padding排除。
3. 用倒数第二层同query的预测边缘与GT边缘的并集决定监督区域。
4. 在该区域计算最后一层mask logits对GT的BCE，按全批选中格数平均，权重1、boundary width3。
5. 原分类、mask BCE、Dice及辅助层损失仍保留。前层硬选区detach，不代表共享网络不受最终BLL梯度影响。

源码：[head接入](scripts/bll_mask2former_head.py)、[目标与损失](scripts/query_bll.py)、[边界选区算子](scripts/bll_core.py)。
