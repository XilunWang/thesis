## 小目标漏检分解

以原固定诊断口径score≥0.5、同类mask IoU≥0.5为准，149个小目标中80个已匹配、69个漏检。

原保存候选中找不到任何类别合格几何的45个小目标，在检查全部query后仍然是45个，新增合格几何0。不能归咎于top-k把大量已有好掩码删掉。

若把几何标准提高到IoU≥0.75，149个小目标中90个没有合格query；另外46个有正确类别且分数≥0.5候选、10个正确类别候选低分、3个正确类别未入选。这是每GT独立候选可用性，未做IoU0.75一对一匹配，不能称46个实际检出或AP75。

## 22个低分和2个分类遗漏是什么情况

对每个低分GT，取IoU≥0.5的query中正确类别最终分数最高者作GT辅助诊断（不是部署选择规则）：21/22的正确类别概率本身就低于0.5，20/22在含背景的8类中最偏向无目标。其mask置信度范围0.8133–0.9810，不是这22例主要的压分项。这里mask置信是预测为前景区域的平均sigmoid值，不等于真实IoU或整体轮廓正确率。

剩余GT2078正确类别概率约0.516，乘mask置信0.901后为0.465，是乘积跨过固定阈值的例子。对所有合格且正确类别已入选的候选另查最高类别概率，前述21例仍全部<0.5；不能仅靠去掉mask因子让它们通过0.5。

2个正确类别没有入选的例子是珊瑚GT144/145：合格掩码query9/32的IoU约0.7895/0.7628，最偏向鱼类，珊瑚概率约0.0000807/0.0001039，掩码已经以其他类别进入保存结果。扩大top-k可把很低分的珊瑚标签加进列表，但不能自动把它们变成可靠检出。

22个低分预测已存在于COCO评价输入中，固定0.5阈值漏检不能直接等同AP遗漏。简单降阈值不改变这些已保存候选的排序，也不能修复45个不合格几何；统一抬分还可能同时抬高误报。

## 下一方向与边界

不修改top-k、阈值、损失或模型，不启动训练。下一项优先复用本次已下载掩码和原图，对45个没有合格几何的目标做固定案例检查：分清漏画、画成邻近大目标的一部分、多个实例粘连、多涂；同时以22个低分但几何合格目标作对照。先判断候选形状具体出了什么问题，再决定是否研究尺度/特征、实例分离或分类学习，不据本次输出直接定位某一层或启用MFRM。

分类分数偏向无目标只说明最终表现，未证明训练匹配、背景权重或特征是因果。全部query查不到合格掩码也不证明骨干看不到目标或最终一层必然是瓶颈。独立GT最佳候选可能复用同一query，不能当可实现召回或预计AP收益。
