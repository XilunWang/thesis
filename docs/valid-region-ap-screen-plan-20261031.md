## 对照设计

| 项目 | A：短程原版对照 | B：有效区域候选 |
|---|---|---|
| 初始模型 | 同一E0 epoch36（原Mask AP32.6222） | 完全相同 |
| head | ValidRegionMask2FormerHead，开关False（已验收等价原版） | 同一head，开关True |
| 唯一算法差异 | 原整画布匹配点 | 有效图像区域匹配点 |
| 数据 | 官方全部3937训练图，原增强与重复图保留 | 相同 |
| 追加预算 | 3轮，每轮1969步，共5907步 | 相同 |
| 优化器 | 全新AdamW，不恢复E0动量 | 相同 |
| 基础LR / 骨干倍率 | 恒定1e-5 / 0.1 | 相同 |
| 其他参数 | 原权重衰减、clip0.01、FP32、batch2、workers2、seed20261012 | 相同 |
| 评估 | 固定第3轮权重，691张官方测试图 | 相同 |

这是E0上的配对微调筛查，不是从COCO开始的36轮正式实验，也不重建原36轮基线。两组都多训练3轮，A的作用是排除“多训练本身”的收益。B只优于未追加训练的E0、却不优于A，不算采样方法有效。

LR1e-5、3轮和单seed是预算受控的预先选择，不是已经验证的最佳设置。明确设置resume=False，只加载模型权重，原E0的优化器/学习率/轮次不带入；从新试验的epoch0开始，停止于epoch3。B不能从A训练后的权重开始。两组使用同一原始权重SHA256：53f9382f8db706be2d91da38b765b6bd5b8f26c33a2434f9a26e795fbbb8376f。

原mask loss采样、所有辅助层损失、匹配成本权重和推理不改。默认不启用任何BLL/MFRM/DSGAT。不挑best、不临时调参、不因第1轮结果不好追加轮次。

## 时间和资源上限

两组总计6个追加epoch、11814次更新。参考同服务器此前E1-P完整单轮1554.68秒（25分55秒），纯训练估算约2小时35分钟；原691图评估实测约179秒/组。加初始化、保存、最终评价和检查，预算预估2.5–3.5小时，不是实测保证。有效区域采样无新增网络，但速度仍需首批实际日志确认。

运行时不与其他训练并发；两组各自目录，保留3轮权重及最终预测。预设总墙钟预算4小时，若超时只在可安全保存的批次/轮次边界停止并记录未完成，不自动超预算、调整batch或删图。未完整完成两组3轮，不宣布AP胜负。

## 预先冻结的投入门槛

以下单位均为AP百分点（不是百分比相对增幅），使用未四舍五入的值。

只有同时满足下列条件，才称“值得进一步复核”，不直接称稳定提升：

1. B总Mask AP≥max(A总AP, E0总AP)+0.5。
2. B的AP_small≥A的AP_small+0.5，且不低于E0的AP_small。
3. B的AP_large相对A、E0均不得下降超过0.3。
4. 没有训练/恢复/评价协议错误，报告全部类别与其他负向变化。

0.5收益和0.3大目标容忍度是为限制成本而预设的工程决策门槛，不是统计显著性阈值、置信区间或可保证涨幅。

- **全部通过**：只支持再做一次独立训练seed的同预算配对复核；另行授权，不自动进入35/36轮。
- **只有很小正差，或只优于E0却不优于A，或大目标超限退化**：不追加长训，不事后降低门槛。
- **B低于A或原E0、未出现小目标改善**：本次微调方案没有提供足够收益依据，归档并停止此预算路线。

短程微调失败不能证明从COCO重训必然无效；但在用户关注投入回报的前提下，不能以“也许长训才有效”为由自动追加预算。单seed通过也不能保证正式训练上涨。
