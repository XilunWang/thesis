## 为什么没有通过

14项程序门槛中，除“小珊瑚相对step0”和“小珊瑚相对随机”的两项外，其余12项通过。珊瑚必须至少提高5个百分点，实际分别下降17.86、17.50个百分点，不能因总体较好而取消这两项。

这不是“整个方法完全没有作用”：小鱼和精确种子定位的提高很明确。但结果也不支持直接进入完整分割模块或追加更长训练。小鱼占留出小目标记录738/776（约95.1%），总体指标主要反映鱼，类别拆分不能省略。

学习组整体覆盖从18.36%升到59.59%，留出组从16.11%升到51.55%，因此整体收益并非只在头的学习图片上出现。珊瑚学习组从40.51%升到50.63%，留出却从50.00%降到32.14%，表明当前珊瑚结果没有同步泛化；样本量小，不能直接归因于单一原因，更不能据此断言R50没有珊瑚特征。

原E0已经训练过官方训练集中的这些留出图片。所谓“留出”只针对本位置头，不等于整个模型没见过，也不替代691张官方验证集。其他类别样本极少（水草7、潜水员3条增强记录），不据此作类别普遍结论。

## 候选重复问题仍在

留出128个视图共12800个候选位置。最终400个一对一匹配、9196格不接触任何小GT、3204个接触小GT但不能新增一对一覆盖的冗余/竞争位置；对应候选利用率3.125%。其中38个视图无小GT，仍按固定规则取100位置，因此不能把全部未接触小GT的格都叫最终检测误报（也可能落在大目标上）。

相对step0，未接触小GT的格由12597降到9196，但冗余/竞争位置从78升到3204。新头开始聚焦小目标区域，同时也有大量名额集中在已经覆盖的区域；尚无实例解码器来区分或拒绝这些候选。不能用空间位置覆盖直接推算Mask AP。
