# 有效区域采样：已有预测收尾与下一步

2026-11-01，仅本地使用两组691图已有预测。无服务器连接、无新前向、无训练。脚本scripts/analyze-valid-region-closeout.py；完整结果reports/valid-region-closeout-20261101/result.json，包含GT得失ID、类别/尺度AP、阈值TP/FP及输入哈希。

## 方法及核验

重新运行COCO segm评价，maxDets=[100,300,1000]，移除bbox避免面积口径混入；两组全部12项指标与既有结果在1e-9百分点容差内一致。类别AP贡献之和精确复现总AP差。按官方COCO忽略规则统计各尺度，在IoU0.5/0.75和score0/0.5下记录一对一匹配得失。score0只是全部已保存top100输出，不是筛选前全部query；这些匹配不是最优几何oracle，不能当作训练因果。不同面积区间按官方端点规则处理，FP面积归属按预测，跨尺度变化不能直接视为误报消失。

## AP为什么没有达标

候选相对同预算原版总AP下降0.2205点。沉船类别下降0.5916点、机器人下降0.5158点，除以7类后对总AP分别贡献-0.0845/-0.0737，共-0.1582点，约占净下降72%。这是宏平均的算术分解，不是退化因果；珊瑚、潜水员和海底也有下降，鱼和水草小幅抵消。

小目标AP8.1122→8.3042（+0.1919）来自类别混合：小鱼28.1105→28.5573，小水草6.9293→7.8165，小珊瑚5.5213→5.1470；小机器人和小海底仍为0，另外两类无小GT不参加该尺度AP平均。因此不是普遍的小目标改善。

## 决策及下一项有意义的问题

1. 按已冻结门槛结束本次有效区域匹配采样路线，不调采样点数、不改loss采样、不自动追加从头训练或第二seed。保留实现/证据作为负结果。微小AP差不证明普遍有害，但不足以支持继续投入。
2. 继续使用E0作为研究锚点；原版追加3轮的A保留为额外预算对照。A的+0.2706点未经多seed复核，不把它宣称新的稳定改进或悄悄替换原基线。
3. 下一项候选聚焦原版小珊瑚的实例形成/分离，而非继续针对padding。依据原24图45个无合格几何案例中30个为珊瑚、44例多涂占优；但样本是诊断选择集，不代表全量比例。这次小珊瑚AP下降进一步说明当前采样没有解决该缺口。
4. 下一步最小产出应是“实例分离/局部细节的设计依据表”：复用既有形状及逐层案例，分开相邻不重叠GT共用候选、巨大无效mask、GT重叠/疑点；核对其增强后目标尺寸及已有stride4表达证据，选定一个可检验的机制假设，再审查相应方法及接入位置。不能仅因低AP就宣布需要更高分辨率或直接接MFRM/DSGAT。已有案例不重复跑，只有关键证据缺失才安排有限前向。
