# 覆盖充分优先选点：无更新几何验证（2026-11-01）

结论：本次冻结范围内通过。优先本实例覆盖像素更多的格子，能在真实分数12图中消除此前非必要的跨界选点，同时在384次增强中保留全部2350条小目标记录和独立分配。本轮只验证标签几何，不改变训练入口、损失、推理、权重或AP，不启动训练。

## 验证前固定规则

计划见`coverage-priority-check-plan-20261101.json`，在运行前写入。

1. 每个原面积0<area<=1024的小实例，支持格仍为与本GT任一像素相交的有效4×4格；不删除任何原支持。
2. 候选依次按本GT覆盖像素数降序（1–16）、当前分数降序、cell ID升序排序。格大小固定，因此像素数等价于本GT占格比例，不是计算全图目标面积。
3. 实例顺序保持原支持格数升序、GT ID升序；仍采用原增广路径一对一匹配。优先格被占用时重分配，必要时使用更低覆盖格，不允许无声丢实例。
4. 这是有偏好的一对一匹配，不是全局覆盖像素和最大化。排序不改变支持图；在原支持可完全匹配时仍能完全匹配。不是用GT改推理选点。

实现为独立离线模块`coverage_priority.py`，正式训练/评价入口没有导入它。原有代表点规则和失败结果保留。

## 两类证据分开

- 全几何：原冻结384次增强（256 learn、128 holdout），逐项核对输入和mask哈希。各用行优先与逆序两组**人工分数**测试等覆盖格的排序敏感性，共768项。不是384次真实模型前向，也不是全3937张数据审计。
- 真实分数：沿用固定12个holdout增强视图、初始/新100/新300/旧300四组完整logits，共48项，同一GT同一分数只改变选点优先顺序。新旧比较调用原make_layout与新模块。

## 极小目标和相邻目标

384次增强中，每组人工分数均处理2350条小目标记录（跨增强重复统计，不是2350个独立原始目标）：

- 两组均2350/2350保留且各占独立有效支持格，无目标丢失。
- 增强后GT面积≤16像素的90条记录全部保留，最小1像素。此定义是本轮几何极小目标口径，不是COCO AP尺寸桶。
- 295条没有任何16/16完整格，均保留部分支持格；两组的跨界格均为295，没有完整格可选时不硬删目标。
- 所选本GT像素数均达到该实例可用最大值（本批未出现为了分离而牺牲覆盖的真实例）。这只是观测，不把算法说成全局最优。
- 格中心在GT外仍有70/79条，来自不同等覆盖排序；覆盖优先不强制中心在内，极小/细长目标可能无法避免。没有把这些算作丢失或改用更宽命中口径。
- 原冻结48次相邻对观察，两组共96项全部各占不同格；这是几何分配，不是训练后的相邻目标召回。

额外构造一个“两个目标争同一优选格、其中一个只有该格可用”的测试，验证另一个可回退到较低覆盖格，两者均保留。再构造真正只有一个格供两个实例使用的不可分情况，必须明确报错，不能静默删除或合并。

## 当前判断及下一步

该修订解决了本次已查到的一个标签几何问题：有充分内部格时，避免仅因分数更高而优先选到混有其他区域的边缘格；无内部格时保留极小目标的原支持。相邻独立性在冻结范围通过。

但之前背景高分来自固定特征与学习后的参数，重排标签并不会改变已有预测。尚未证明重新训练会减少背景高峰、改善覆盖或提高AP，也没有补出历史训练标签。原300步实验仍failed。

如果继续，下一步只做独立开关的无更新接入验收：关闭时原损失/输出一致，开启时正样本数不变、梯度有限且正负方向正确，邻近目标均有正监督、保存恢复保持规则配置。通过后再决定是否值得一个固定预算单因素对照，不能因几何通过自动开训。
