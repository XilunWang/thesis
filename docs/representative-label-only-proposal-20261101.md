# 下一候选取舍：只换代表点，保留旧位置BCE（2026-11-01）

## 决策

暂缓上一版“三项损失”的接入候选，不调整其0.5/0.25/0.25权重，不覆盖原失败证据。本轮提出并做本地缓存原型验收的最小候选：**只把几何固定种子改为实例内部独立代表点，损失完全调用旧position_loss。**

这不是删掉全部重复惩罚：除全局保护的代表格外，其余有效格仍是旧BCE负样本，重复格和区域外格都继续受抑制。去掉的是独立新增的相对排序项及其分组配比，恢复旧的绝对正负BCE及归一化。核心训练代码与既有三项模块没有改写；本轮只有独立缓存原型检查，不训练、不连接服务器。

## 为什么选这一项

上轮固定案例分解表明，三项方案同时改变了正点位置、重复惩罚形式、负样本分组归一化、空图权重；局部受压既有原来就存在的竞争，也有初始状态中新产生的不利方向。两例不足以支持重新调配比，更不足以证明哪项会提高实际覆盖或AP。

只改变标签选点、其余保留旧定义，可以建立单因素对照：如果后续学习发生变化，至少不再混入独立排序损失和负项权重变化。本候选是验证“实例内部选点”的消融，不是已证明的完整改进或论文创新。

## 三个方案的差异

| 项目 | 已完成300步的旧位置头 | 三项损失候选（暂缓） | 本轮最小候选 |
|---|---|---|---|
| 代表点 | 几何固定种子 | 实例内分数偏好、一对一 | 同左的实例内一对一规则 |
| 正点损失 | 正BCE均值 | 0.5正BCE均值 | 直接复用旧正BCE均值 |
| 重复候选 | 纳入所有负格BCE均值 | 独立相对排序项，权重0.25 | 纳入所有负格BCE均值 |
| 区域外候选 | 纳入所有负格BCE均值 | 独立区域外BCE，权重0.25 | 纳入所有负格BCE均值 |
| 有正负样本时 | 正/负均值各0.5 | 三项分别归一、加权 | 正/负均值各0.5 |
| 没有小目标的图 | 负BCE均值，权重1 | 区域外负BCE权重0.25 | 旧负BCE均值，权重1 |
| 网络、冻结E0、推理top100 | 原规则 | 原规则 | 原规则 |

“旧位置头”不是原Mask2Former基线或BLL。这里没有修改分割模型损失。

代表点选择仍按当前detach分数，在每个原始小目标自身stride4支持格中一对一最大基数匹配；不能共用格、不能跳过目标。全部代表格共同为正，其余有效格全部为负。无法满足一对一容量时明确失败。

## 本地检查做了什么

复用前序56组缓存：18视图两阶段真实分数共36组，以及固定邻近/历史碰撞视图两种合成排序共20组。FP32/FP64各检查一次，共112次实际PyTorch loss/logit梯度检查，没有模型前向或参数反传。

- 每个目标都有一个独立正代表点；正样本数与旧几何种子一致。
- 全部有效非代表格均为负，没有把整个实例前景设成正或忽略。
- 代表点logit梯度为负、其余有效格为正、padding为0。
- **标签未变化的格，其logit梯度与旧损失逐位一致。** 这包括全部小目标支持并集之外的有效格，因此未普遍减弱区域外的直接抑制。其原因是正负格总数不变、旧BCE公式和归一化不变。
- 98次固定相邻目标配对压力检查均保留两格为正；不会因为距离近而删掉其中一个。
- 空图保留旧的完整负均值权重1，未沿用三项方案的0.25。

这些是GT辅助标签/直接导数一致性，不是模型召回、背景误报率或AP提升。共享参数仍可能把局部影响传到其他位置；“同一格的直接导数不变”不等于“参数梯度或更新后的预测不变”。

## 仍有哪些风险

1. 从已有高分选代表点可能强化偏好，初始位置头响应近随机时尤其如此。
2. 一对一容量能保护实例计数，却不证明两个相邻目标有足够可区分的特征。
3. 旧BCE保留负监督，不代表一定能解决重复候选；旧300步结果本身已有重复峰和珊瑚退化。
4. 目标几何点附近的正监督会被挪到选中的其他支持格，未必更适合后续mask形成。

因此本轮结论是“得到可解释的单因素候选”，不是“已经修好”。

## 对上一轮判据的明确修正

此前把所有成对共享参数方向都不压制设为总体通过条件，过于严格。局部负方向是诊断证据，不能单独替代实际学习或AP结果，也不是提升AP必须满足的数学条件。

上一版固定协议与passed=false结果完整保留，不重新判成通过。后续新候选若制定准入，应把不丢目标、无正负标签冲突、默认关闭等价、有限梯度及原模型冻结作为工程硬条件；共享参数方向作为新旧对照诊断，是否有效仍需预先冻结的同预算留出评价。不得用“放宽判据”把未知收益变成已通过。

## 下一步边界

若继续，只对这个标签单因素候选做一次有界的真实模型无更新对照：固定此前3视图及step0/300状态，沿用相同目标对，核验原输出、梯度隔离，并与旧BCE在相同位置比较参数方向。不再扩图或为了消除全部负方向反复调规则。

本轮未实现正式训练入口、未授权参数更新。将来若评估300步学习，必须同一step0起点、数据顺序、优化器和预算与已有旧位置头比较；不能让候选从step300继续学习后再和旧step300直接比较。还需另行冻结收益与停止规则；保留珊瑚类别保护，不拿鱼的增长掩盖珊瑚退化。
