# 独立小目标位置头：无参数更新的接入验收

2026-11-01。用户授权继续位置头接入验收；没有训练，没有创建优化器，没有改变E0配置或权重。结论仅为监督与梯度隔离可运行，不是小目标检出或AP收益。

## 改了什么

新增 `scripts/isolated_position_head.py`。原Mask2Former-R50路线保持原样；实验脚本单独建立一个344577参数的位置头：

```text
冻结的E0 R50 → 原像素解码器 → 原query解码器 → 原分类与mask
       └ C3(stride8)/C4(stride16)
         → detach → 各位置通道LayerNorm → 各自1×1投影到128通道
         → C4双线性上采样到C3尺寸 → 相加/ReLU
         → 3×3卷积/ReLU/1×1卷积 → stride8单通道位置logit
```

128通道为本次最小实现选择，未经宽度搜索或效果验证。分支前向只接收图像特征，GT仅用于生成训练标签；尚未实现位置top-k、query初始化、新mask预测或与原版结果合并。新位置头随机初始化，没有学到任何检测能力。

监督对象是增强后仍保留、**原始标注面积0<area≤1024**的全部实例，不是仅原版漏检实例。按上一阶段确定的占据格最大匹配规则，每实例一个独立正格；允许在本实例实际占据的格内重新分配。遇到无法一对一分配时明确报错，不静默丢弃。没有改变实例mask。

有效图像范围内其余格是“非种子位置”负格，不能称为语义背景；大目标和小目标的非种子内部也可能是负格。padding格不参与损失；与有效图像相交的边缘格保留。每图正格BCE均值与负格BCE均值各占一半，再对图平均；没有正格时只用负格均值。这避免负格仅因数量多而淹没正格，但不证明梯度已最优，也不证明邻近位置竞争已解决。本步骤没有BLL或新增边界监督。

## 异常及边界

首次连接在登录前关闭，用户开机后SERVER_READY。运行结束时，PowerShell对远端shell退出码变量的展开造成外层`exit`参数错误，SSH包装命令返回1；Python自身结果为passed=true，三样本完成标记均存在。随后单独读取结果、比对源码哈希并确认进程已退出、GPU占用0 MiB。没有为外层命令错误重跑验收，也没有改动通过标准。

本次仅证明可以隔离地计算位置监督，不能证明位置头学得会，更不能保证最终AP提高。原版输出不变是因为新分支尚未参与输出，未来合并可能带来误报、重复和100个输出名额竞争。固定样本无匹配不足不等于全训练集都没有；当前代码对不足显式失败。
