## 范围与可复核性

从[上一步归属诊断](label-only-no-touch-20261101.md)中选“旧top100未入选、新top100入选、4×4候选格不接触任何GT”的候选。看图前固定规则：按距任意GT像素≤8、(8,32]、>32增强像素分三层，每层4个；按新排名、图ID、seed、cell排序，全局原图去重。11个排名1、1个排名2。这是高排名定向抽查，不是随机样本，不能把12例比例外推到4281个新进入候选或净增1080。

服务器首次连接失败，用户开机后检查通过。服务器仅CPU重放12张图的原数据增强和预处理，全部12张规范化输入、GT哈希与历史缓存精确一致。原图文件SHA也与本地一致。逆变换回原图后，12个候选中心仍均不在任何原始GT内；因此本批不是单纯增强造成中心GT归属丢失的证据。未逐一验证整个候选格的逆映射归属，不把中心结论扩展为整格结论。

每张面板从左到右：原图全景（绿线标注、红圈位置）、原图无覆盖细节、增强后无覆盖细节、增强后绿线标注与红色4×4候选格。中间两图待查看点在中心。原图低分辨率处放大只便于看像素，不增加真实细节。图片由原像素裁切生成，无生成式补图。

## 对路线的影响

1. “无GT”不是“真背景”的同义词。距离很近的候选也不能自动作为正确检出，疑似漏标不能作为收益加回。
2. 不能将所有增长解释为边缘错一点：远处也有沙地/岩面响应。只放宽命中半径或修改统计口径会隐藏这个问题。
3. 这一步说明位置头仍有选择性不足的迹象，尚未证明损失、标签或特征哪个是根因。既有小目标覆盖收益不等于分割AP收益。
4. 本次抽查结束，不追加训练、不自动扩大看图。若继续，建议先在已有缓存中对这12个固定案例比较训练前后分数及排名，配对已标注小目标，区分背景自身升分和相对排序变化；只形成机制证据，不用这12例调阈值或训练参数。是否做该项由用户决定。
