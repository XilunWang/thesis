# 邻近实例干扰训练：具体假设与设计准入

2026-11-01。承接query-design-review-20261101.md。状态：待验证设计，不是已实现模块、已确认创新或正式实验计划。本次仅检索原始资料并写设计，无服务器、训练、模型前向、依赖安装。

## 核实到的已有做法

[MP-Former官方decoder](https://github.com/IDEA-Research/MP-Former/blob/main/mask2former/modeling/transformer_decoder/mask2former_transformer_decoder.py)的prepare_for_dn_v5：将GT mask按area方式降到注意力尺寸，按目标所占面积和noise_scale确定翻转概率，用随机数异或门；类别标签也有随机替换。所查路径没有按相邻GT身份选择干扰区域。随机翻转可能落在邻居上，不能说它完全没有训练邻居干扰；其他分支含平移/缩放，不能把整个MP-Former概括成只有独立噪点。官方示例mask噪声为0，设计对照必须明确所用变体。

[Learning Equivariant Segmentation with Instance-Unique Querying，NeurIPS 2022](https://papers.neurips.cc/paper_files/paper/2022/hash/53a525a5f8910609263ffd130ef370b8-Abstract-Conference.html)已经研究有辨别力的query、跨图实例检索和几何变换等变性，并包含Mask2Former实验。因此“让query区分实例”不是新概念。

[Contrastive Mask Denoising Transformer for 3D Instance Segmentation](https://openreview.net/pdf?id=hkcrLAj8F9)已有mask去噪和近位置多实例相关设计。第一次PDF链接被浏览验证拦截，本次仅据原始论文可检索正文/摘要确认方向，不声称已核验其完整代码或与本方案完全等价。2D/3D不同不自动构成创新。

检索范围有限，没有证明本候选全球首次。以下只是相对已查MP-Former路径可明确描述的差异，不能写“首次邻域感知去噪”。

## 唯一研究假设

在相邻同类目标容易被合并的训练情形，若引导query在保留目标身份线索的同时接触受控的邻居区域，并学习恢复自己的完整实例，可能比等预算非定向干扰更有利于实例分离。最终应反映到不使用GT的普通query，而非仅让辅助分支答案更准。

依据是既有E0中少数清楚的非重叠GT共用候选、多涂以及低分形状候选；不是已证明的训练根因。32例全层无合格几何未必有邻居干扰，候选不能承诺覆盖全部小目标漏检。

## 拟修改的具体对象

只改变训练辅助query的cross-attention允许区域构造；不向图像复制对象、不更改实例标注，不把邻居标成目标。不恢复BLL、不改变原12544点匹配策略，不追加推理裁剪模块。

设增强后的目标mask为Mi，同类邻居为Mj。在具体解码memory尺度l上，先得到目标支持区Si,l。选择邻居中不属于目标的有效区Di,l，构造允许区域Ai,l=Si,l并集Di,l，辅助输出目标仍为原Mi及类别yi。

Di,l要求取邻居的受控部分，不取整幅背景；样本、邻居规则、面积预算和随机种子先固定。普通100query仍执行原匹配，辅助query已知对应Mi；普通query不能通过self-attention读取GT引导分支。推理去掉全部辅助query，只保留原普通路径。拟接入位置是decoder训练输入及逐层attention门构造，非最终mask之后。

保留目标GT作为监督，不等于模型训练输入得到正确答案的无条件保证；训练辅助GT引导属于已有MP类机制。是否传递到普通分支尚未知，必须单独判断。

## 必须先解决的设计反例

同类目标i与j若都使用完整Mi并集Mj，且query输入类别/位置等线索相同，就可能得到相同输入但要求两个不同输出。禁止这种构造，不能指望新增loss自动消除歧义。

仅“不完全相同”也不证明任务可辨认。当前最小候选保留目标自身支持区，只增加受控的部分邻居；需要在实际stride32/16/8上检查目标是否消失、i/j支持门是否碰撞、邻居独有区是否仍存在。原图分开的目标在粗尺度上可能变成同一格，必须记录为该候选不可区分，而不是硬改标签或偷偷采用占有规则解决所有问题。

若需要额外目标中心/内点位置作为身份提示，这是第二个机制，不可藏在“只换噪声”名下；应修改研究问题并让所有对照共享同样提示。当前不引入该提示、不声称现草案已解决所有身份歧义。

## 能区分假设的对照，尚未运行

| 组别 | 作用 |
|---|---|
| E0式同预算训练 | 排除额外训练本身 |
| 固定版本原MP参考 | 区分是否只是已有引导机制有效 |
| 等辅助query、同标签扰动、同干扰面积预算的非定向区域对照 | 排除增加训练量/任意空间扰动的效果；与候选采用相同目标支持区及可辨性约束 |
| 邻近同类实例定向干扰候选 | 唯一被检验差异为干扰来源是否针对邻居身份 |

非定向对照不能随意用独立散点而候选用大连通块，再把差异全部归于邻居语义。至少报告/控制扰动面积和空间连通性；完全配平做不到时必须承认混杂，不以单一对照宣称机制已闭合。预算、权重、具体规则尚未冻结，不安排这些训练。

反例及停止条件：相邻目标在实际尺度上普遍无法保留不同支持、合格训练实例对极少/集中于少数图、或现有证据不支持邻居合并对应本问题时，停止该设计。若未来只辅助分支改善而普通query无收益，或候选不优于等预算参考及非定向对照，不宣称成功，不靠增加轮数延续。

## 下一步最小可执行工作（无训练）

只做该新设计所需的“训练标注可辨性与覆盖审计”，不重新跑45例失败诊断：先核查本地是否保存足够的增强后真实mask；复用已保存实际增强的固定12图及既有7类选择，不重新挑有利图。统计相邻同类对数量、有效支持区、在stride32/16/8的碰撞和目标丢失，输出可行/不可行例及按图统计。原标注可用于预筛，但不能冒充增强后模型输入。

本地若只有面积和匹配摘要、没有增强后mask，应先如实列出缺失文件；不自动用新随机增强替换旧输入。必要数据取回与新的模型运行分开授权。只得到“可构造”也不代表值得训练；还需要完成现有方法差异审查及冻结单因素方案。审计不修改3937/691划分或重复图，不删除困难实例。
