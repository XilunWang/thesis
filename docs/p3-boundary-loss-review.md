# WaterMask边界学习：论文与原始代码核对

2026-10-21。本文完成方法核对，未实现或运行新增损失，也未接入模型。

## 先说人话

原方法先画出物体的大致形状，再画更精细的掩码。最后一次学习重点看两类地方：前一步自己画出来的边缘，以及人工标注的真正边缘。两者合起来，既检查画错的位置，也覆盖该画却没画准的位置。前两步仍学习完整掩码，避免只学边缘而丢掉物体主体。

推理时还有另一条规则：大部分区域沿用前一步结果，边缘附近用最后一步的结果替换。这是BMS；训练中的边界损失是BLL。只加损失，不等于同时实现了这套推理融合。

## 实际训练规则

| 项目 | 原始实现 | 对我们意味着什么 |
| --- | --- | --- |
| 三阶段输出 | 14×14、28×28、56×56的同一个RoI掩码 | 不是Mask2Former的三个不同尺度全图输出，不能直接套用stage编号 |
| 前两阶段 | 完整区域BCE，权重0.25、0.65 | 原方法没有抛弃完整掩码学习 |
| 最后阶段 | 对选中的边界区域算BCE，权重1 | 监督目标仍是前景/背景掩码值，不是边缘类别 |
| 找边缘 | 二值掩码经过7×7核：中心48、其他位置−1；绝对响应严格大于0.15×49才选中 | 对二值邻域，等价于至少8个邻域位置与中心不同；包括边界两侧，不等于评价用的内边界带 |
| 区域来源 | 第二阶段预测sigmoid≥0.5形成二值掩码；与第二阶段GT分别提边界，然后取并集 | 仅用GT边界是简化版本，不能称为原BLL复现 |
| 对齐最后阶段 | 并集以bilinear、align_corners=True上采样至最终掩码尺寸，再按≥0.5二值化 | 不可默认用nearest，也不可省略二值化步骤 |
| 归一化 | 选中像素BCE求和，除以整个正实例批次的选中像素总数，分母最小为1 | 不是每实例分别平均；大边界实例会占更多权重，适配时需明确是否保留 |
| 边界取值/梯度 | 硬比较得到区域，区域选择本身不向上一阶段传播梯度 | 最后阶段区域内BCE仍对最终logits产生梯度；不应把整个损失detach |
| padding | `padding='same'`保持尺寸，默认零填充 | 全前景掩码在图像外缘也可能出现边界；测试不能误以为边界必定为空 |

原代码空边界的分母保护不等于已保证整个函数对零实例安全：前两阶段的BCE平均仍需单独验收。原三阶段配置只在最后一阶段进入边界分支；若扩展更多阶段，不应假定代码自动更新了每一轮的pre_pred。

## 论文符号与代码的区别

已目视确认PDF第6页，而非只依赖搜索摘要或OCR：

1. 论文式(4)将响应≤阈值的位置记为B=1，这实际上对应非边界区域；式(5)用B保留M2、用1−B替换成M3，与“保留内部、更新边缘”的逻辑相符。
2. 式(6)附近又把B(M2)与B(G2)的并集描述为需重点学习的边界区域。若把式(4)的同一个B直接代入，这里会出现语义冲突。记录为论文符号口径不一致，未经作者澄清，不擅自断言哪一处一定是笔误。
3. 官方代码区分得更清楚：`generate_block_target(... ) == 1`是边界；训练取两种边界的并集；推理用`!=1`取得非边界区域。实现与测试以这个明确行为为准。
4. 论文文字写padding为1，但7×7核在stride1下用padding1无法保持原尺寸；官方代码用same。不得机械照抄文字中的padding1。

原始`water_roi_head.py:93–104`推理时用宽度4，即9×9核，从第二阶段预测生成非边界区域，上采样后用第二阶段logits覆盖最终logits的非边界部分。训练7×7、推理9×9与论文5.1的设置相符。训练辅助损失候选不应顺手改动E0推理规则。

## 对Mask2Former的决定

**结论是可以借鉴这种监督方式，但不能只改一个loss配置就声称移植完成。** Mask2Former没有同一RoI的14→28→56细化链，且不同decoder层可以产生不同匹配关系。必须明确如何获得同一实例的前后预测、如何固定边界尺度，以及如何复用原匹配结果。

先前提出的GT-only辅助BCE仍只是简化候选，不是本轮已确定的E1。当前先不新增网络分支、DSGAT、MFRM或推理融合；也不确定损失权重，不据测试集反馈试参。

下一最小步骤调整为：**先独立验证原版边界目标与三阶段损失规则，再决定取完整规则还是GT-only简化。** 这样先确认理解和实现正确，不把接入错误与方法无效混在一起。

待执行小测试规范（CPU合成张量即可）：

- 输入：三阶段logits[N,1,14,14]、[N,1,28,28]、[N,1,56,56]及对应GT[N,H,W]；固定随机种子，不读取测试集、不训练。
- 案例：矩形、平移轮廓、细线、空前景、全前景、贴边物体、零实例、无边界区域及批次大小变化。
- 验收：独立逐像素计数与官方边界函数逐点一致；阈值附近行为符合严格大于；并集/上采样区域一致；区域内BCE值及全批像素归一化一致；空集合有限且保持计算图。
- 梯度：最后阶段选区内有梯度、选区外该项梯度为零；前两阶段完整BCE仍有梯度；硬边界选择没有额外反传路径。
- 之后才设计Mask2Former适配：同一次匹配结果的复用、GT/预测网格、训练padding有效区域、带宽、最终层范围、lambda=0等价检查。不能将合成测试通过写成实际框架接入成功。
