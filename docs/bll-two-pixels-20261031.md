# 两个漏涂像素：插值共享与背景梯度的精确追踪

2026-10-31。只读保存的ID7/query38输出，本地CPU计算，无模型前向/更新、无训练或服务器连接。没有改正式BLL或候选权重。

## 确认的局部原因

增强图坐标采用从0开始的(y,x)。问题像素为(622,1007)、(623,1007)，GT均为前景，均在实际选区且位于有效图像内部，当前前景概率分别0.3868、0.4490。不是GT下采样丢失，也不是padding被误当监督。

两者都由同一组粗网格节点(155,251)、(155,252)、(156,251)、(156,252)双线性插值得到，节点logits分别-2.3441、2.3366、-1.1883、3.1425。各自插值权重为：

| 像素 | 四节点权重（按上述顺序） |
|---|---|
| (622,1007) | 0.546875 / 0.328125 / 0.078125 / 0.046875 |
| (623,1007) | 0.390625 / 0.234375 / 0.234375 / 0.140625 |

同一批节点也被附近其他输出像素使用。对这两个像素有直接耦合作用的选中像素范围为y618–629、x1002–1013，共144个：64前景、80背景。独立逐像素计算插值权重重叠，得到每个邻居的贡献，全部加和与PyTorch自动求导一致。

| 目标像素 | 前景推动提高 | 背景推动降低 | 合计方向 | 背景/前景作用比 |
|---|---:|---:|---:|---:|
| (622,1007) | +0.00069545 | -0.00186136 | -0.00116591 | 2.6765 |
| (623,1007) | +0.00075994 | -0.00156968 | -0.00080974 | 2.0655 |

数值为本实例选中像素平均BCE在原生logit空间负梯度经插值的方向，没有执行任何一步更新；全批平均会同倍缩放本实例，不改变比值/符号。

贡献较强的背景位置包括(621,1009)、(621,1010)，前景概率分别0.8400、0.9254。它们是真实的多涂背景，要求降低预测是合理监督。问题在于它们与两处前景共享预测节点：合理收边和局部压制同时发生，不能靠简单删掉背景解决。

## 对照与证据边界

手工按align_corners=False公式重建四节点权重，精确复现两个logit；用K_pq=sum_j(A_pj*A_qj)计算每个相邻像素残差(sigmoid(logit)-GT)的贡献，总和与autograd一致。

代数上去除共享背景项后，方向分别变为+0.00069545/+0.00075994；若假设每个高分辨率输出是独立变量，两像素自身BCE方向也都为正。这确认了本次反向作用来自共享插值节点上的背景贡献。二者只是定位反事实，不是实际删除背景、构建高分辨率分支或已验证修复。

这证明固定输出中的局部梯度机制，不证明所有训练退化由它造成，不证明stride4必然无法表示该轮廓，也不代表修改监督后模型一定改善。

## 怎样调整监督：当前决策

1. **继续保留原GT像素标签，不恢复占有标注。** 两像素没有标错，问题不是把它们再扩大成整格前景就能正确解决。
2. **不统一提高前景权重、不屏蔽邻近背景。** 此例各半平衡等效前景相对权重1.8901，低于使两像素反向的2.6765/2.0655阈值，所以仍失败。不能据此把全局权重设成2.68或更大：这是针对已知两个像素反推，会削弱真正需要的收边；此前四实例对照已观察到背景反向项增加。
3. **下一步优先验证与粗网格共享关系相适应的局部选点/加权候选**，保留前景与背景两类监督，并同时检查漏涂补回、背景收回和新外扩。必须在固定更多目标上冻结规则评估，不能对这两个坐标特判。当前未确定具体可用规则，不称已解决。
4. 如合理监督调整仍不能兼顾，才考虑可独立学习的更细局部输出；仅把同一粗预测再放大不会解除共享关系。此为后续结构候选，尚未实现或授权训练。
