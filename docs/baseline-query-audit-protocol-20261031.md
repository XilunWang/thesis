# 原版全部query候选检查协议

固定E0 epoch36、原测试尺度(1333,800)、FP32、batch1，沿用baseline-scale-pilot-20261031/selection.json全部24图，不根据本次结果增删样本。仅前向，无优化器、反传或训练。检查每图全部100个query，而不是扩大最终输出数；不改变正式预测。

独立复现原后处理：去padding、双线性还原原图、logit>0为mask；类别softmax包含背景，取前7类的query×类别top100，再乘正mask像素平均sigmoid概率。要求与原fusion输出逐位一致，与保存预测mask一致、分数误差<1e-4（另报告实际误差）。权重/状态/标注/原预测不变。

对所有非crowd GT按IoU>=0.5和>=0.75分别检查：全部query无合格几何；有合格query但没有正确类别query进入top100；正确类别已进入但合格候选全部最终分数<0.5；存在合格且分数>=0.5候选。与既有固定阈值一对一匹配状态交叉，不把独立GT最佳候选当实际召回或AP。拆解正确类别概率、背景概率、mask置信，区分top-k未入选与已保存但低分。保存全部query的原图RLE和概率，便于本地复核。

重点报告面积<256和256–1024的小目标，含既有漏检与检出对照；尺寸用COCO标注面积。24图是已有探索样本，不能外推691图比例，不能用GT辅助候选替换正式输出。结束后根据结果判断优先查掩码形成还是分类/候选选择；不自动改阈值、模块或训练。
