# E1-P：原GT像素BLL正式对照实验计划

2026-10-31制定；后续用户已授权入口通过后仅第一轮。入口已验收，见[pixel-bll-formal-entry-20261031.md](pixel-bll-formal-entry-20261031.md)。下文“仅计划/尚需”保留制定时门槛，当前只允许首轮，后35轮仍未授权。E1-P是旧BLL监督方式的独立修订，不占用历史E2/MFRM、E3/DSGAT编号。旧E0/E1结果、源码和权重不覆盖。

## 问题与比较对象

要检验：保持网络、边缘选区和额外损失权重不变，把BLL的真值从“粗网格占有标签”改成“增强后原GT像素”，能否减少边缘多涂，改善边界，同时避免损害整体分割、大目标和小目标检出？这是待验证假设，不承诺涨点。

| 组别 | 做法 | 状态/作用 |
|---|---|---|
| E0 | 原版Mask2Former-R50，无BLL | 已完成36轮；Mask AP32.6，大目标AP47.8；判断新增监督有无净价值 |
| E1 | 旧BLL，占有目标作为粗网格BCE真值 | 已完成36轮；Mask AP33.0，大目标AP46.6；判断新监督是否改善旧适配 |
| E1-P | 独立PixelBLL，预测插值后对原GT像素计算BCE | 仅新增训练这一组；成绩待测 |

E1-P对E1是监督方案修订对照，对E0是整体新增损失对照。E1-P若只胜E1、仍不如E0，只能说部分修复，不能宣布方法整体更好。不重训E0/E1；可复用两组最终预测重算同口径诊断，无需重新训练或推理。

## 怎么跑：同起点、同预算

- 官方UIIS训练3937张、测试691张，7类；保留train/XL_266.jpg与val/XL_679.jpg重复图。不删图、重划分或改变原增强过滤/补取规则。
- R50、单卡FP32、batch2、workers2、seed20261012、36轮；每轮1969步，总70884步，最后1图批次保留。
- 原训练增强：LSJ 0.1–2、1024裁剪、翻转等。采用原Runner随机流程，不用短试跑每图固定增强或16图循环。
- AdamW基础LR1e-4，骨干倍率0.1，原weight decay/参数分组/梯度裁剪；第27/33轮各衰减×0.1。正式cuDNN等后端设置与E0实际运行配置核对，不直接沿用诊断设置。
- 预测分辨率、网络结构、最终Hungarian匹配、前层预测与GT边缘并集、width3/阈值0.15、weight1、原分类/mask BCE/Dice/辅助层损失保持不变；无MFRM、DSGAT或新边界头。
- 唯一研究改动是冻结的[原GT像素监督公式](bll-pixel-protocol-20261031.md)：占有GT只定位选区；选区整数展开、排除无效padding；最终logits双线性插值align_corners=False，与原二值GT计算选中像素BCE，全批选中像素平均，无前景/背景重加权。此改动包含监督网格及相应归一化，不声称单独隔离了每个数学因素。
- 计划新目录work_dirs/uiis_e1p_pixel_bll_r50_36e及reports/uiis-e1p-pixel-bll-36e-evaluation。正式入口须独立，拒绝覆盖，使用训练锁；现有head overlay不是正式训练入口。

已通过：helper/同前向损失与梯度核对、3937图每图一次增强正监督检查、原生Runner无更新保存恢复、16图20步实际更新与显式循环中断恢复。它们不等于新COCO起点及正式多worker入口已通过。

尚需在单独授权的入口准备阶段完成：

1. 独立正式config/入口，只允许上述监督差异及输出目录变化；将解析后配置与E0/E1实际配置逐项比对，冻结源码提交、数据、预训练及配置哈希。
2. 核验COCO权重加载：只有预定类别头不匹配，骨干/decoder/mask投影加载正确；分类头初始化规则一致。在COCO起点真实数据上验证loss与有限反传，不能用E0热启动20步替代。
3. 核验正式Runner和workers2在epoch边界的保存恢复，包括模型、优化器、调度器、计数、种子/采样进度及允许的随机性限制。显式循环workers0的短试跑不能替代。任意步崩溃不宣称精确续接；保留现场，按最后完整epoch checkpoint恢复前先核对，不自动丢弃/重放未记录步数。
4. 固定三组比较脚本与输出结构：旧脚本有E0/E1固定路径，需要适配三组但保持旧口径，使用旧预测回归核对后冻结；在看到E1-P结果之前完成。正式Boundary AP不在本轮承诺范围内。
5. 实际启动时检查服务器、无其他训练、磁盘/保存策略、数据和依赖哈希。记录首轮完整耗时与显存，不从69.57秒热启动试跑外推36轮用时。

## 跑完和谁比、看什么

固定最后epoch36，在全部691张官方测试图运行同E0/E1推理与COCO mask评价，保存原始预测。推理尺度(1333,800)、原max_per_image等配置保持一致；COCO maxDets=[100,300,1000]，AP评价不先用0.5阈值筛选。差值使用未四舍五入原值。

1. **整体效果**：三组Mask AP、AP50/AP75、AP_small/medium/large及7类AP。AP75不是边界指标。
2. **是否少漏小目标**：沿用score≥0.5、同类Mask IoU≥0.5、置信度降序一对一最高IoU匹配，报告全量普通GT分母、分尺寸匹配/漏检与未匹配非忽略预测数；crowd沿用原规则。0.3/0.7只作固定敏感性对照，不挑最好阈值。
3. **边界是否改善**：原分辨率、对角线2%内部边界带、图外背景、3×3腐蚀，沿用已验算实现。分别报告每组匹配集合及E1-P/E0、E1-P/E1两两共同GT集合；三组共同GT作为统一配对表，给出全体和大目标边界IoU、改善/下降数量、覆盖率及多涂/漏涂量。相同GT上的三组值直接比较，不用不同集合均值硬比。
4. **避免只看容易实例**：共同匹配指标必须同时列新增/减少漏检及覆盖率；旧E0/E1的871个共同大目标仅为历史参考，新三组交集数可能不同，不能直接拿旧70.63%/69.64%当新集合分母下的基准。
5. **固定案例**：针对E1-P对E0、对E1分别展示共同大目标边界下降最多2例、上升最多1例、变化最小1例、新增漏检中对照原IoU最高2例；并列按GT ID，不只挑改善图。缺少某类案例则如实注明。

边界诊断是有检出条件的Boundary IoU，**不是Boundary AP**；必须连同检出变化解释，不能推导全局边界精度或因果贡献。诊断尺寸分组small<1024、medium<9216、其余large；区别于COCO面积边界口径。

## 预期与预先固定的判断

希望看到：相对E1多涂减少、配对边界IoU提高；相对E0整体AP不下降、大目标不再退化，小目标漏检不增加。不预报具体涨幅，不设“至少涨1点”的无依据承诺。

- **初步支持继续研究**：在同一三组共同GT集上，全体及大目标边界均值均高于E0/E1；Mask AP与AP_large不低于E0，固定0.5阈值小目标漏检数不高于E0。报告所有其他负向变化和覆盖率；这只是严格的单次筛选目标，不是显著性或稳定收益证明。
- **部分修复或取舍**：只优于E1但未达到E0，或边界改善伴随AP/检出下降，明确写“部分改善/存在代价”，不笼统宣布成功。不能用某一类涨分掩盖其他退化。
- **核心假设未获支持**：边界未改善或退化，尤其多涂未减少；即便AP上涨，也不能声称本次解决了边界问题。保留结果，先解释证据，不立即堆MFRM/DSGAT或调参重跑。

不因微小正差异称稳定有效，不预设统计等价区间。单种子且此前反复查看官方测试集诊断已影响方案选择，须明确披露探索性和测试反馈；不是未触碰测试集上的确认性验证。若方向值得继续，再单独规划配对多种子或外部数据验证，不在本轮自动增加预算。
