# E1-P AP下降与大目标诊断（2026-10-31）

## 结论

仅使用本地已保存的三组691图预测、官方标注和原图，无服务器连接、推理或训练。确认本次大目标AP下降有两条直接表现：少数类别的置信排序恶化，以及部分实例的掩码几何退化。不能把AP下降全部归因于边界变差，也不能据此证明训练中的某一损失项是唯一原因。

大目标AP E0/E1/E1-P为47.7696/46.5519/43.9269。相对E0下降3.8427点，相对E1下降2.6251点。

仅6个大机器人类别对E0净下降3.8427点贡献-2.997点，约78%；对E1贡献-1.667/总-2.625点，约64%。这是小样本类别对宏平均的敏感性，不是删掉类别的理由。其余六类平均AP相对E0仍下降0.987点、相对E1下降1.118点，问题并非只有机器人。正式成绩保留全部7类。

全尺寸Mask AP下降1.6173点中，机器人贡献-1.1162点；潜水员-0.5383、海底-0.3228、水生植物-0.2723、珊瑚-0.0573，鱼+0.1031、残骸+0.5866。相对旧BLL主要为机器人-0.9088、残骸-0.5707、海底-0.4610点，其他类合计后得到总-1.9545点。

## 排序恶化：正确预测被高分错误预测挤到后面

机器人大目标在IoU0.50时，E0和E1-P都匹配5/6个GT；IoU0.90均匹配4/6个，十档平均召回都为78.33%。但AP61.99→41.01，IoU0.50的AP65.49→45.13；不能用“最终能找到的机器人变少”解释这段下降。

在机器人类别达到50%召回（3个TP）之前，E0有0个FP、E1有2个FP、E1-P有3个FP。因此达到相同召回时精度为100%/60%/50%。E1-P总FP数量更少（IoU0.5的全部非忽略FP为168，E0为321），仍掉AP：AP关心错误排在哪里，不只是错误总数。这些FP属于COCO大目标面积评价规则下的非忽略预测，不表示每个都对应一个大GT。

- GT1098（官方类别robots，图XL_1775.jpg）：掩码IoU E0 0.97977→E1-P 0.97855，几乎不变；最终分数0.97593→0.90747；大目标非忽略机器人排序从第2降到第6。
- GT3724：IoU0.97297→0.96212，分数0.95728→0.87807，排序第3→第9。
- 图689（XXL_90.jpg）没有robots标注，纸币形区域被预测为robot，E0分数0.85085、E1 0.97695、E1-P 0.97110；新方案中排到第2，压在多个真阳性前面。此处按官方GT评判，未调整标注。
- 海底也有同类表现：IoU0.5最终TP112→113，但达到50%召回前FP176→234；大目标AP23.76→21.14。不能用“检测数量稍增”推断AP应当提高。

保存的预测仅包含最终score和二值mask，尚不能区分最终分数变化来自类别概率还是掩码质量分数，更不能直接称分类头损坏。这里证明的是输出排序退化。单独对同类别全部score做严格单调变换不会改变其COCO排序/AP；调整0.5展示阈值也不能据此修复正式AP。

## 掩码本身也存在退化

大目标AP在IoU0.50时61.20→57.42，IoU0.75时51.35→47.71，IoU0.90时30.69→26.88；并非只有最严格边缘要求才下降。对应宏平均召回91.55%→91.91%、79.22%→81.01%、50.16%→50.60%，再次说明召回与AP必须分开。

另一方面，E0/E1-P在score0.5共同匹配864个大GT，掩码IoU87.94%→87.59%，边界IoU70.61%→70.13%。从原版达到IoU0.85变为达不到的有43个，反向改善25个；IoU0.90为下降36/改善24。这些是固定共同目标上的阈值跨越，不是官方COCO AP的独立贡献分解。

- GT3557，reefs，XXL_367.jpg：IoU E0/E1/E1-P =0.960/0.605/0.591。原版覆盖珊瑚顶部，两个BLL版本明显漏涂一部分。
- GT1845，reefs，XL_2620.jpg：IoU=0.908/0.897/0.543。新方案把相邻区域也涂进目标，出现明显多涂，不是只沿边缘差几个像素。

三组共同846大GT中，珊瑚454例边界IoU64.97%/64.11%/64.19%，海底43例68.81%/67.48%/66.83%。鱼249例83.08%/81.60%/83.08%。退化具有类别差异，不能称所有大目标都变差。展示的最差案例是用于解释现象的有意选样，不代表发生频率。

## 漏检阈值与真正的找不到

score0.5下，相对E0新丢失42个大GT，其中41个仍有同类IoU≥0.5预测，只是分数低于0.5，1个掩码IoU不足；同时新增匹配51个，净多匹配9个。相对E1新丢失54个，其中53个低分、1个IoU不足，同时新增41个。这里是固定阈值诊断，不是COCO AP；不能把新增低分未匹配都描述为模型完全没有找到目标。

## 核验和证据

脚本scripts/analyze-e1p-ap-drop.py重新计算三组COCO，前六指标与冻结报告在1e-10容差内一致；每类/面积/IoU的101点插值AP均由排序TP/FP独立重算，与COCO数组差小于1e-8；类别宏贡献精确加回总体差值；输入SHA256前后不变。结果reports/e1p-ap-drop-20261031/result.json，passed=true。

固定案例脚本scripts/render-e1p-ap-cases.py，图reports/e1p-ap-drop-20261031/cases.png，数值cases.json；绿色GT、红色预测，已人工查看渲染。前两条珊瑚案例按共同匹配掩码IoU降幅选取；机器人例子对应排序诊断，非随机样本。

## 当前判断与下一步

已经回答“AP在已有预测上为什么下降”：高分错误与正确预测排序恶化，特别是6个大机器人类别的宏平均影响，加上珊瑚/海底等实际掩码退化。没有回答“训练中为何产生这些变化”的全部因果链；单种子也不能区分稳定设计缺陷和训练随机波动。

停止长训练。若继续机制核查，最小步骤是针对固定排序案例，用现有E0/E1/E1-P权重仅做前向，导出最终score组成、对应query和掩码概率，区分类别分数变化与mask质量分数变化；需现有模型环境，另行执行，不以此自动立项评分模块或改阈值。多涂/漏涂案例单独追踪，不把全部损失归咎于评分。
