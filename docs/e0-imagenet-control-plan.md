# E0-IN：仅ImageNet骨干初始化的受控实验方案

日期：2026-10-29。状态：方案已制定，入口未实现、权重未下载、启动前验收未执行、训练未启动。用户本轮只授权制定方案。本方案不解除其他暂停任务，不替代E1–E3模块实验编号。

## 1. 问题与对照

在现有Mask2Former-R50、UIIS及36轮协议下，把完整COCO实例分割预训练替换为仅ImageNet骨干初始化，最终Mask AP会变化多少？

对照为已完成的E0，简称E0-COCO（不是新增训练），精确Mask AP为32.6222177。新实验编号E0-IN，原版Mask2FormerHead，不添加BLL、MFRM、DSGAT或其他模块。比较的是两种初始化策略的整体影响，包括骨干权重来源、分割模块及query是否经过COCO训练；不能把效果进一步单独归因为某个子模块。

不预设E0-IN应低于25.7或32.6，不用接近WaterMask论文数字作为通过标准。该实验不是论文Mask2Former-R101的复现，也不是R50/R101骨干对照。

## 2. 唯一研究变量：初始化方式

E0实际备份配置checkpoints/e0-backup/config-first.py的model.backbone.init_cfg=None；load_from指向mask2former_r50_8xb2-lsj-50e_coco_20220506_191028-41b088b6.pth。分类层按7类构建，不兼容的COCO分类参数不加载。

E0-IN必须同时完成两处变化，不能只清空load_from：

```python
load_from = None
resume = False  # 仅首次启动；正式中断恢复另走同实验恢复入口
model.backbone.init_cfg = dict(
    type='Pretrained',
    checkpoint='<已核验并冻结的ImageNet ResNet-50本地权重路径>')
```

上面是方案示意，不是可直接执行的完整配置。权重来源拟采用原MMEngine环境的torchvision://resnet50；实现前记录该别名在固定版本中的实际解析URL/权重版本，确认是ImageNet分类权重，冻结文件SHA256后改用本地明确路径。不得使用随软件版本变化的DEFAULT隐式换权重，不得从COCO checkpoint截取骨干冒充ImageNet初始化。权重身份未核验前禁止正式启动。

只有backbone加载该权重；ImageNet分类器fc不属于检测骨干，应明确列出不加载的键。Pixel Decoder、Transformer Decoder、query、分类和掩码预测部分按原框架默认规则初始化，不加载COCO、E0最终、E1或技术试跑参数。保留原R50所有层结构、BN/frozen_stages设置，不因初始化改变而放开冻结参数、调大骨干学习率或延长训练。

## 3. 必须保持的条件

以E0实际config-first.py/config-resume.py、run-protocol.json及原训练入口为依据；不从当前BLL配置删减来构建。

| 项目 | E0-IN固定条件 |

| 骨干设置 | frozen_stages=-1；BN requires_grad=False、norm_eval=True；保持E0其余配置 |
| 数据 | UIIS原始3937训练/691评价图，7类映射及标注、图像哈希一致 |
| 重复图 | 保留官方原划分，XL_266.jpg/XL_679.jpg不删、不换集 |
| 批量与精度 | 单V100 32GB，batch=2，workers=2，FP32；无AMP/梯度累积 |
| 数据加载 | shuffle=True，persistent_workers=True，drop_last=False，最后一批1图 |
| 预算 | 36轮，1969步/轮，共70884步，不因收敛慢加轮数 |
| 优化 | AdamW lr=1e-4，weight_decay=0.05，betas=(0.9,0.999)，eps=1e-8 |
| 参数分组 | backbone lr_mult=0.1，其余分组/归一化及query衰减规则沿用E0 |
| 调度/裁剪 | 第27/33轮学习率各乘0.1；梯度max_norm=0.01；自动LR缩放关闭 |
| 训练增强 | 翻转0.5，LSJ 0.1–2.0，1024×1024裁剪，原过滤/补齐/标准化 |
| 随机性 | seed=20261012，原Runner设种子方式；cudnn_benchmark=False，不额外改确定性选项 |
| 推理 | 1333×800等比缩放，无测试增强；max_per_image=100，其他推理参数不变 |
| 选模 | 固定epoch36，不选best，不根据691图成绩调整训练 |
| 环境 | 原Python3.10、torch2.1.2+cu121、torchvision0.16.2+cu121、mmcv2.1.0、mmengine0.10.7、mmdet3.3.0；启动前核验 |

## 6. 最终评估与判读

完整36轮后，固定epoch36对全部691图执行与E0相同的推理/COCO评估，保留原始segm/bbox预测、配置、日志及权重哈希。Mask AP为主要指标，同时报告AP50、AP75、APs/APm/APl和各类AP；不把bbox AP当分割主成绩。保存预测后用已有独立审计入口重算，确认一致。唯一重复图敏感性若补做，应另表说明，不替换官方划分主结果。

主差值预先定义：Delta = AP(E0-COCO) - AP(E0-IN)，使用未舍入值计算；展示可保留一位小数。

- Delta为正：在本次固定预算下，完整COCO初始化优于仅ImageNet骨干初始化。
- Delta接近0或为负：如实报告，不能据此改配置追求预期；单种子不定义统计显著性。
- 无论是否接近25.7，都不能认定已复现WaterMask论文对照；骨干、作者实际初始化及其他协议尚未完全对齐。
- 固定36轮只衡量相同预算下结果，不证明ImageNet初始化的最终性能上限；若要延长训练须另立实验。

预期产物为初始化审计、配置差异、训练曲线、最终指标对照表及结论说明。本轮不预填新AP，不承诺下降幅度。
