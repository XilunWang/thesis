相反，这3张图的有效位置分数中位数，从初始约0.01降到−11.810/−12.102/−11.300。全12例也都出现候选升分、中位数下降。这里的“多数位置”包含所有有效位置，不把所有未标注区域认定为真背景。

为分开两项变化，额外做数学替换：

- 保留其他格初始分数，只把该格换成新300步分数：12例都排第一。
- 保留该格初始分数，其他格换成新300步分数：12例排名仍在191–1449，全部进不了前100。
- 相对旧300步也一样：只换该格为新分数，12例都第一；只换其他格，排名75–1572，仅2例能进前100，均不能到最终前二。

这说明**仅“其他位置下降”不能解释这些点的最终高排名，自身升分是关键组成部分**。数学替换仅用于分解分数，不是实际运行的新模型，也不证明优化器或某条监督的因果。

## 真实小目标是不是被整体压低了

12个视图共58个已标注小目标，每个目标统计4×4支持格中的最高logit（任一GT像素相交，与原位置覆盖口径一致）：

|比较|内部最高分上升|下降|抽查候选相对小目标最高分的优势增大|
|---|---:|---:|---:|
|初始→新300步|56/58|2/58|57/58|
|旧300步→新300步|48/58|10/58|58/58|

不能说新方案普遍让小目标分数降低：绝大多数内部峰也升高，但同图抽查候选升得更强。这里58项包含同一张图候选与多目标的比较，不是58个独立样本；未确认语义的候选也不能统称背景。对应位置覆盖仍为旧25/58→新29/58，不是分割收益。

若把小目标内部“初始最高的那个固定格”一直跟踪，47/58比初始下降、43/58比旧方案下降。但目标内部最高点允许随训练改变，而该标签方案本身只选择一个代表格，其他内部格可以被压低。固定旧峰下降不能直接判为小目标整体受压，必须与内部新峰一起看。

10/12号图没有小目标，不能说背景高点挤掉了本图小目标；11号仅1个小目标，新方案覆盖反而改善。此次没有做替换候选后的一对一覆盖因果实验。

现在可以回答的是：这个位置头不仅压低了大多数位置，也学出了极高的标注外局部峰；本批存在明显背景纹理响应，且不能用“小目标都降分了”解释。这支持检查选择性和泛化问题，不支持简单降低背景权重、改命中半径、提高阈值或追加训练。
