# 冻结E0特征读出：3图最小验证结果

日期2026-11-01。3图14GT已完成冻结前向与CPU离线拟合，未更新模型、未创建优化器、未训练。

## 结论先行

不能把小目标失败统归为R50没有区分能力。在7个原各阶段均无合格形状的目标中，GT128/129/130可从R50中间特征线性读出合格几何，提供局部正证据；其余4个仍未决。4个早期合格后丢失目标本就存在合格mask embedding，其中66/67的GT辅助新读出进一步明显好于原输出。

本次没有证明像素解码器丢信息：探针在GT124/126也失败，但捕获的原模型早期向量能够在同一份mask_features上精确重建合格掩码。这直接说明“探针没找到”不等于“特征不存在”。因此停止用探针失败归因，不能据此开训新模块。

## 执行与验证

首次SSH在登录前关闭；用户确认开机后12:17连接恢复，V100空闲，磁盘约20GB。固定E0、FP32、原尺度、3图2/19/42，单图一次正式前向，用hook捕获C2–C5、mask_features与十阶段embedding/raw logits。导出耗时19.33秒；300条S9结果分数误差0、mask变化0，30次embedding点积重建logits逐位一致；state_dict前后相同、参数梯度全为空。

CPU探针耗时76.32秒，7种读出×14GT=98项，未超20/30分钟止损预算。岭回归解析例与线性读出/双线性恢复交换校验通过。14个原模型最佳向量的原图mask均与缓存一致，作为存在性证据。运行结束GPU为0MiB；没有操作关机。

全部约800MiB特征已下载到本地，三份特征SHA256与导出记录一致；导出与探针源码、result关联哈希核验通过。本地独立重建14GT×5种真实特征的70项读出，TP/FP/FN/邻居多涂像素与服务器逐项一致，原S9/全阶段IoU与旧缓存逐条一致，见local-verification.json。首次本地运行因未将已有.local/bll-libs加入搜索路径而报ModuleNotFoundError: torch；补上该已有目录后通过，没有重装依赖或更改实验参数。

## 三类具体判断

- GT66/67：原S9最佳IoU0.495/0.449，新mask_features向量达到0.804/0.757，原全阶段最高仅0.507/0.596。此图的最终mask特征能表达更好形状，但当前query未产出它。可支持查询/学习利用不足的局部解释，未定位训练原因。
- GT128/129/130：原全阶段最高0.296/0.250/0.162；分别在C3/C4/C4读出0.550/0.636/0.555。不是所有漏检都能用“骨干看不见”解释。但探针使用每实例GT，不能保证网络自动找到这些向量。
- GT13/14/125/127：所有这些简单读出均未达到0.5，保持未决。不等同小目标信息丢失，也不据此更换骨干。

## 探针校准的失败必须保留

已知存在合格向量的7例中，岭回归只在5例找到了合格mask_features读出；GT124/126未通过，IoU0.476/0.297，但原早期向量分别可精确重建0.612/0.762。该校准失败触发协议限制：所有读出失败只能报告未决，不作为特征不足或像素解码器损失的证据。未调整正则、阈值、采样预算或选样来掩盖失败。

## 实现细节与复核边界

固定seed20261101，负采样用SeedSequence([seed,GT_ID])、随机对照用SeedSequence([seed,image_id])，各层共享同GT样本。没有调参；λ=1e-3、无偏置、全部前景、最多4096负像素、三组等额及容量不足再分配。有效区RMS使用原有效矩形在特征网格上的面积权重。RGB在原图像素直接读出，随机256通道在mask_features网格；两者均不进入原网络。

模型只在导出时前向，离线读出在CPU进行、不加载模型权重。全部原始标注像素保留；邻居是其他已标注实例除去当前GT重叠区。记录每项TP/FP/FN、前景精度/召回、邻居FP及未抽中负像素FP，详见result.json；没有裁ROI隐藏远处多涂。此最小方案同GT拟合/计分，不能外推新图泛化，不能作为论文AP结果。

## 下一步边界

此次最小验证结束，不自动扩图、搜索探针超参或继续训练。优先研究问题可收窄为“已存在的实例线索如何被query利用”，但尚没有可开训的改进方法；若另行继续，应先提出固定R50、保持预算的具体机制及可推翻预期，不能重启DiveSeg、BLL、简单有效区域或单格邻居候选来替代结论。
