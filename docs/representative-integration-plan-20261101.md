# 代表点与重复约束：冻结接入协议（2026-11-01）

本协议于GPU验收前固定，机器可读配置见 `representative-integration-plan-20261101.json`。只准许前向、反向和梯度分析，不准许任何优化器更新或训练；结果不理想时停止并报告，不在本次验收中改权重重试。

## 目标定义

保留grid4位置头及冻结E0；只新增独立、默认关闭的损失适配器。关闭直接调用旧 `position_loss`，原训练入口、权重、原模型输出和top100推理规则不变。新方案没有接入原Mask2Former分割损失，也没有给query或mask增加分支。

启用时，每个原始面积0<area<=1024的GT实例从自身stride4占据格内，按已detach的当前分数偏好进行一对一最大基数匹配。先支持格少者、再GT编号，格内按分数/索引稳定排序；不是最大总分优化。容量不足明确报错，绝不丢目标。

所有代表格先全局保护；支持并集中的其他格才参与重复约束，且只归属一个实际覆盖它的实例。按到代表格的网格距离及GT编号打破归属歧义。不用距离NMS，不把邻居代表点标成负样本。

## 固定损失

每图 `L = 0.5 L_positive + 0.25 L_duplicate + 0.25 L_outside`；图间等权平均。

- `L_positive`：各实例代表logit的正BCE，按实例平均。
- `L_duplicate`：`softplus(z_duplicate-z_representative)`，先按实例内重复格平均，再按有重复格的实例平均。
- `L_outside`：原始小目标支持并集之外的有效格负BCE，按格平均；区域外并不等于语义背景，其中可有大目标。
- 空项为0，不重新分配权重；无小目标图仅剩0.25倍区域外负BCE。这与旧方案的空图权重不同，属于明确的候选定义，不是旧损失数值等价。
- 0.5/0.25/0.25用于把正监督与两类抑制分别明确，不声称是最优配比；本次不做权重搜索。

## 分开报告两层互相压制

1. **损失到logit层**：代表点梯度<0（下降损失会提高分数）、重复格>0、padding为0；A的实例局部项对B代表logit直接导数必须为0，反之亦然。
2. **共享参数层**：计算A局部项的参数梯度g_A，以及B代表logit的参数Jacobian J_B。`-g_A·J_B`是无穷小SGD方向对B分数的预测变化。也检查完整损失方向对双方分数的影响。

归一化方向小于-1e-6，记录为共享参数压制；不以标签保护通过代替这一检查。此数不是实际AdamW更新，没更新参数，不能当训练收益或预测一定变化。工程验收和邻近方向验收分开；任何失败不得自动调参或开训。

本协议不授权新一轮位置头学习，也不声称AP提高。
