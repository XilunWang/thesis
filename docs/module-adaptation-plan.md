## 保留的研究原则

借鉴WaterMask思想，针对Mask2Former实际接口重新设计，不把RoI过程与query迭代视为等价。候选逐项独立验证，再凭证据决定组合；不承诺三个模块全部保留，不把模块名称当创新结论。正式实验从同一约定初始化独立开始，不继承E0/E1最终权重。

数据、训练预算与评价规则按冻结协议，差异明确登记。先进行与改动相称的机制/数值/资源检查，任何新训练另行授权；不以工程通过代替性能收益。
