## 为什么loss更低不能当收益

候选会在目标支持范围内偏好已有高分位置，并把原正标签移走。因此同一权重上loss变低可能仅是监督点选择造成的，不代表真实能力提高。一对一分配也不是全局总分最优；本轮不以loss大小或GT辅助覆盖作收益门槛。

工程条件已满足，停止追加这一轮接入诊断；不再为了让所有局部方向变正而扩图、改阈值或调权重。候选是否有用仍未知。

如果继续，下一步应制定并冻结一次有明确止损的同起点位置学习对照：候选与既有旧位置头使用同一step0、数据顺序、优化器、300步预算和评价，不从step300续训后直接对比旧step300。若复用旧对照，必须核验运行与评价协议确实相同；任何变化都不能再称单因素对照。必须保持珊瑚保护及密集邻近目标评价，不能仅看总体鱼类增长。

这一步只允许准备计划和入口，不授权训练；不得把工程通过等同收益或自动开始300步。后续是否启动需要明确授权。无论位置学习结果如何，都不是Mask AP，最终仍须验证实际分割输出。
