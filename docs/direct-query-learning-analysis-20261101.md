# 直连查询：3轮是否不够，是否值得续训

2026-11-01。本轮只分析本地已有训练日志、配置、启动/终态记录及三组评价结果；未连接服务器，未构建模型，未训练或新增评价。

## 判断

现有证据不能区分“训练尚不充分”和“结构收益上限较小”。日志没有显示候选的优化优势逐轮扩大，最终结果是小目标AP/召回改善、整体AP增益很小，并有类别间收益抵消。当前不建议直接续训，更不建议扩展36轮；值得做的下一项是补看已保存第1、2轮权重的评价曲线，不需要增加训练。

3轮是预设预算，不是收敛证明。总AP门槛未通过的事实保持不变；事后诊断不能更换末轮结果、降低门槛或选最好一轮宣称原筛查成功。

## 1. 训练损失是否仍有明显学习势头

|---|---|---|
| 总loss | 16.0636 / 16.1919 / 15.9597 | 16.0530 / 16.1991 / 15.9599 |
| 最后层分类+mask+Dice | 1.4301 / 1.4399 / 1.4161 | 1.4289 / 1.4333 / 1.4167 |

第3轮最前500步与最后500个已记录步的总loss：A为15.3827→16.1951，候选15.3662→16.1924。两组同步上升，不能只挑最后一批loss下降说候选尚在快速学习，也不能据此认定过拟合。

## 2. 是否没学起来或被参数设置卡住

已有实际启动检查表明新增投影参与优化，LR1e-5、WD0.05，并非被冻结或错归backbone的1e-6学习率组。终态已核验347份优化器状态均完成5907次更新。无非有限损失、梯度异常或中断；全程固定LR，无调度器尚待触发。

但日志没有保存新增分支独立梯度、参数更新幅度或它相对于原特征的激活强度。因此不能仅凭全局grad_norm或“执行了更新”确认新增分支学充分。第3轮全局裁剪前grad_norm窗口均值为A310.80、候选303.34，均采用max_norm0.01裁剪；原版也如此，不能据此认定只有候选被压住。AdamW的有效更新还依赖动量及二阶矩，不能把裁剪比例直接当参数学习速度，也没有依据现在擅自提高学习率或放宽裁剪。

## 3. 最终结果显示什么

相对同预算原版A：总AP+0.0950，AP50+0.2960，AP75−0.0846，小目标AP+0.6759、小目标AR+1.9294，大目标AP+0.0847。存在召回和小目标的积极信号，但没有整体精度明显提高的证据。AR提高而AP提升有限，可能涉及新增预测的排序、误报或高IoU质量，单凭汇总指标不能断言具体原因。

| 类别 | 候选相对A的AP变化 |
|---|---:|
| fish | +0.3079 |
| reefs | −0.1366 |
| aquatic plants | −0.1344 |
| wrecks/ruins | +1.0668 |

总AP按7类平均。wrecks/ruins贡献+0.1524个总AP点，其他6类合计−0.0574，最后净增+0.0950；这说明改善并不均匀，不等于“小目标改善已经全面转化为总AP”。该类在验证集无小目标，不能把它的全尺度类别AP提升解释成小目标来源。这里没有重新计算类别×尺度交叉指标，不能指定小目标收益来自哪一类。

## 4. 怎样补上最关键的证据

当前仅第3轮有验证AP，没有第1、2轮AP轨迹。两组配置均interval1、max_keep_ckpts3，日志记录了每轮保存；本轮未连接服务器确认现存文件，不能把配置当当前文件存在的证明。

建议下一项：先核对服务器A及候选的epoch1/epoch2仍在，再只评价这4个已有检查点，与现成第3轮结果形成1→2→3轮曲线。采用原691图和原指标；这是事后诊断，独立保存，不修改正式末轮准入脚本，也不挑最好权重替代本次末轮结果。

- 若候选相对A的总AP差和小目标AP差逐轮扩大，且大目标保持，才增加“仍在学习”的可信度，可讨论另行冻结一个有限、两组同预算的续训方案；3点仍不能保证继续有效。
- 若优势已在第1轮出现、随后持平或缩小，或小目标收益伴随其他类别持续下降，则更支持当前设计收益有限，不追加训练。
- 若结果忽高忽低，不能称趋势；优先停止投入，不用无限延长来等待好结果。

这不是再次做接入工程测试，而是补上当前真正缺失的性能随轮数变化证据。当前结论是“值得补已有检查点评价，不值得现在直接续训”；本轮没有执行这4次评价，没有任何训练授权。
