## 回答“3轮不够，还是作用不大”

1. 候选总AP不是逐轮上涨：32.8631→32.7799→32.9878；相对原版的优势第2轮最大，第3轮缩小。无法支持“多跑就能越来越领先”。原版也先降后升，单次三个点不足以分离随机训练波动、短期调整与真正的收敛趋势。
2. 第2→3轮候选总AP增加0.2080，但原版增加0.3913。只看候选自身上涨会误读，两者差值反而减少约0.1834。
3. 小目标确有后期积极线索：候选第2→3轮小目标AP增加0.4189，同时原版下降0.2573，两部分共同形成最终0.6759的优势。不能把优势扩大全部解释成新增分支学到了更多；也不能说改善完全是原版退化，因为候选自身确实增加。
4. 大目标相对原版逐轮从略低变为略高，未出现持续牺牲大目标的走势，但差值较小，不等同稳定收益。
5. 原版第1轮总AP33.0731还高于候选第3轮32.9878。这只能提示延长轮数不保证提升，不是新的公平主对照，也不能事后选择各自最好一轮替代固定末轮实验。

**判断：现有证据更符合“局部有收益、整体优势小且波动”，而不是已证明“只因3轮不充分”。不建议直接追加训练或改成36轮。** 这不是证明结构无效，也不是证明已收敛；只是目前不足以支持继续投入训练成本。第3轮总AP门槛未通过仍成立。

停止本次筛查，不追加轮数、不改学习率、不降低门槛。若还要研究，先利用已有预测定位小目标新增检出是否可靠、哪些误报/排序或类别退化抵消了收益，明确可检验的问题后再立新方案；不再用重复接入验收或无限加轮数代替判断。本轮没有开展新的实例级诊断。
