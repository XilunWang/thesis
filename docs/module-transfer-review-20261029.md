# DSGAT与MFRM迁移判断：源码、现有机制和实际问题

2026-10-29。用户要求暂停模型修改和训练，先判断投资是否合理。本次只读本地固定版本源码、论文、E0配置和已有预测记录；仅执行四节点原始邻接函数探针及结果汇总，没有模型构建、推理、反传、优化器或服务器任务。

## 决策

**不建议将原版DSGAT或原版MFRM作为下一项迁移实施任务，更不建议直接正式训练。** 这是基于当前架构、错误证据和适配成本的项目决策，不是“已实验证明它们在Mask2Former上无效”。

- DSGAT：撤回“优先接入即可改善小目标”的建议，不列为当前优先研究模块。独特的远距离特征图交互尚未与我们的具体错误建立联系，原实现计算代价明确。
- MFRM：不按原模块迁移；其“对已有实例做空间细化”的思想可保留，但query适配需要新设计，不能继续称作简单移植或默认论文创新。当前也不实施这个新设计。
- 旧E1→E2→E3不再是确定执行顺序；保留编号与历史，不删除负结果，不启动替代训练。

## 2. DSGAT实际做了什么

water_mask_head.py:15–22的adj_index先计算全部节点的欧氏距离，然后topk（默认largest=True），选择**距离最远**的k个节点；论文§4.1明确写farthest，因此不是误写成近邻的明显bug。四个标量节点[0,1,3,10]、k=1调用原函数，节点0选节点10，验证通过。不能把它描述成保证相似、同类或同实例的邻居聚合。

GAT:70–117在最高分辨率全图特征上用3×3/stride3卷积分块，两层图注意力后转置卷积、插值并残差相加。WaterMaskHead:299–321将它放在gff分支两次卷积之后；WaterRoIHead:49–53传入x[0]，即全图FPN高分辨率特征。它不产生新实例或提高输出网格分辨率；高层特征距离不等于物体边界或语义类别，聚合到背景的风险目前没有真实特征证据量化。

**原实现并非内存稀疏。** cdist、adj和每层e/attention均构造N×N张量。按我们的1024画布、stride4特征、token3计算，节点85×85=7225；单个FP32矩阵为199.13 MiB/图，batch2为398.26 MiB，前向有多种矩阵及训练保存量。此处只是一个矩阵的解析大小，不是总显存实测、不预测必然OOM、不估计训练时长。k=11不消除这些稠密分配。论文表5的8×8原图patch设置也记录超显存，但不能直接当作我们设备的结果。

**与原模型的关系：** E0不是缺乏空间交互的普通CNN掩码头。实际配置有6层多尺度可变形注意力（stride8/16/32，8头、每层级4采样点），再融合stride4浅层特征，输出256通道stride4 mask feature；另有9层query decoder的掩码交叉注意力和query自注意力。DSGAT的高分辨率远距图交互并非与这些运算完全相同，特别是stride4未直接进入那6层encoder；所以不能断言“完全重复、一定没用”。但仅有这种差异，不足以证明值得增加全图稠密计算。原版已有跨尺度/上下文能力，而目前没有证据表明“缺乏这种远距图关系”是小目标漏检主因。

**判断：当前不迁移DSGAT。** 若未来重启，必须有真实特征或受控证据证明远距关联能处理一个现有机制未处理的具体问题，同时有完整前后向的资源预算；不能仅凭模块名字或原论文整体增益重新开训。

## 3. MFRM实际做了什么

Stage:142–200需要四个具体输入：局部实例空间特征[N,C,h,w]、该实例掩码logits[N,1,h,w]、全图gff特征[B,C,H,W]、带图像索引的RoI框[N,5]。它从全图对同一个RoI做SimpleRoIAlign，与局部空间特征和sigmoid掩码拼接，再以1×1及Fusion卷积融合，减半通道，并按阶段上采样。Fusion:120–139使用膨胀率1/3/5卷积加池化分支。

WaterMaskHead:312–336输出14、28、56掩码；但默认pre_upsample_last_stage=False意味着最后阶段先在28网格产生logits，再插值到56，**不能误说成最后一步一定有56×56的可学习高分辨率特征处理**。初始局部特征来自mask_roi_extractor，阶段mask按roi_labels选通道；目标按同一框crop_and_resize。WaterRoIHead推理还用BMS融合阶段内部与边界，不能将原完整结果全部归功于MFRM。

**Mask2Former没有这些直接对应的接口。** 100个query是[B,100,256]向量，mask feature是全图共享[B,256,H/4,W/4]；einsum生成各query掩码。它没有原MFRM所需的[N,C,14,14]实例空间特征、RoI框及检测框分支。将query广播成空间图不等于原RoI实例特征；用预测mask导出框要解决空mask、断裂、裁剪、训练与推理一致性和映回原图；用GT框训练而预测框推理会引入额外分布差异。改成全图query细化又需要另一套结构与计算预算。

原模型已有高低层融合与迭代mask预测，但没有原MFRM那种实例局部空间卷积细化。因此“局部细化”存在真实结构差异；**差异不代表原MFRM可以直接迁移**。特别是固定56×56 RoI掩码不保证比当前stride4全图预测更精细，对大物体更不能只看“14→56”就认定提升空间分辨率。

**判断：不迁移原MFRM，不把它作为确定的下一个模块。** 若将来确有局部轮廓瓶颈，可重新研究面向query、保留坐标与实例对应的细化方案；必须作为新适配设计审查，而不是将PPT里的A+B+C拼接视为原论文实现。

## 4. 论文消融究竟支持什么

论文表4是在WaterMask、ResNet101-FPN、1×下：完整25.6，去DSGAT24.2，w/o MFRM23.1。尤其§5.3明确w/o MFRM是**关闭特征融合、保留主体**，不是拆掉整个细化分支。它支持组件在该组合内有贡献，既不是“原Mask2Former加DSGAT涨1.4”，也不是“加MFRM涨2.5”，更不是独立模块充分有效的证据。当前E0 32.6与论文分数也不能直接做模块收益比较，初始化与最终配置证据限制见既有协议审计。

## 5. 我们实际的问题与模块是否对得上

重新汇总已有3748个普通GT记录，不重跑推理。口径保持score≥0.5、同类IoU≥0.5、分数排序一对一匹配；以下为未匹配原因分类，不是TIDE或AP损失归因。

| E0未匹配GT原因 | 小目标 | 中目标 | 大目标 |
|---|---:|---:|---:|
| 有同类IoU≥0.5候选，但分数低于0.5 | 176 | 202 | 262 |
| 无合格候选，存在同类0.1≤IoU<0.5且未归入异类高重合 | 122 | 109 | 50 |
| 无同类合格候选，有异类IoU≥0.5 | 11 | 16 | 16 |
| 匹配竞争 | 0 | 0 | 1 |
| 按此优先级其余无同类IoU≥0.1 | 230 | 40 | 4 |
| 合计 | 539 | 367 | 333 |

176/539约32.7%、262/333约78.7%已经有几何上合格的低分候选。不能据此称提升分类分数就能恢复全部目标，也不能把IoU≥0.5叫精确边界，但这直接否定“所有未匹配都因为细节没恢复”。只做后置掩码细化不能直接产生缺失query或重新设计分类分支；mask质量变化可影响最终得分，故也不能断言对分数完全无影响。DSGAT可能间接影响分数，但我们尚未建立其独特图机制与这些错误的对应。

大目标条件边界仍有提升空间，但E1相对E0的边界下降，是改变监督后的退化证据，不是E0缺少DSGAT/MFRM的证据。此前BLL占有目标外扩偏向也不会因盲目增加细化分支自动消失。既有大目标oracle显示更好候选可能已存在，实际还涉及候选排序，不能全归为掩码细节不足。

## 6. 下一步边界与论文定位

先结束“按三个名字依次拼起来”的预设路线。当前不安排实现或正式训练；保留E0、E1和全部负结果。不自动改成另一套新模块。

若继续研究，应先选一个有证据且能独立验证的问题。例如区分低分候选、缺失候选和已检出物体轮廓误差，再决定做识别/排序还是空间细化。现有统计足以暂停原迁移计划，但不足以保证哪个替代方向一定成功。新的正式训练必须先有明确接口、作用对象、低成本机制检查、计算预算和对照定义。

毕业论文中，本次是方法选择依据，不是实验创新。DSGAT/MFRM只列相关方法或被审查的候选，不画成已确定创新模块；E1是直接迁移的探索结果，不用它证明未实施模块无效，也不为补偿沉没成本继续训练。

验证：原始邻接函数最远节点探针通过；每尺寸原因计数守恒，合计与既有阈值诊断一致；JSON证据含源码与输入哈希。未修改任何模型源码、权重、数据规则、训练配置。文档仅本地，服务器未同步，Git远程由用户负责。
