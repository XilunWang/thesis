# 原GT像素BLL候选：同尺度接入协议

冻结日期2026-10-31。仅接入与验收，不授权训练。候选名PixelBLL，独立head/config，旧E1核心代码、权重、数据和正式入口保持不变。

## 固定公式

- 原Mask2Former骨干、像素decoder、query decoder及mask输出分辨率不变；无新增可学习参数或细化模块，推理不变。
- 复用同次前向的最终层原Hungarian匹配，同query倒数第二层预测仅用于选区，选区detach。
- 选区沿用旧方案：有效stride4网格上，前层二值预测边缘与GT占有目标边缘并集；width3、7×7阈值0.15。占有GT只用于找检查区域，不再作为BCE真值。
- 选区按整数stride重复展开，排除纯padding及有效图像外像素。最终logits双线性插值到补齐GT尺寸，align_corners=False；对增强后原始二值GT计算选中像素BCE。
- 全批所有选中像素统一平均，weight1。前景/背景同权，无错误加倍、错误选点、类别重加权或面积重加权。
- 保留所有原分类、mask BCE、Dice及辅助层损失；只新增loss_bll_pixel。关闭weight0完全走父类，不出现该loss键。
- 每个匹配实例必须保留至少一个被选中的原前景像素，否则显式报错。空匹配返回图连通零。FP32、单进程；AMP/DDP未支持。

## 验收范围与界限

本地：固定保存输出与既有离线候选loss/gradient对照；122单像素及有效半格；空匹配、关闭、批量归一化、非法匹配/GT/padding；有限性及前层硬选区无梯度。

完整环境：加载现有E1权重严格校验结构状态；真实ID22固定seed20261043，包含小目标及有效半格；同一完整模型前向的输出上复用相同RNG比较父类、关闭候选及开启候选原loss项，避免把GPU重复前向噪声误当接入错误。验证新loss与独立直接公式及输出梯度一致，总loss可反传到网络参数且有限，模型/权重不变；不创建优化器。

这不是36轮效果验证、完整全训练集增强审计、Runner保存恢复验收或峰值资源证明。旧候选的小目标局部梯度冲突仍可能存在，协议固定不等于已解决性能问题。训练仍需另行授权及完整运行协议检查。
