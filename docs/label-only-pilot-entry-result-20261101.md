## 发现及修正的检查问题

独立恢复复核的第一次运行在CUDA随机状态断言处失败。复核脚本当时先恢复检查点、之后才首次初始化CUDA；而实际Pilot入口先构建CUDA模型，再恢复检查点，两者顺序不一致。

将**复核脚本**改为与实际入口相同的“先初始化CUDA，再恢复”后，CPU/CUDA等全部随机状态严格一致。保留了第一次失败日志，没有改动实际训练入口、恢复工具或冻结计划，没有放宽一致性断言。结论仅针对实际入口使用的初始化顺序；未声称通用恢复工具在CUDA尚未初始化的任意调用场景都已修复。
