# 原训练增强可见性审计：固定协议

只运行原E0训练数据pipeline，不建模型/优化器，不改数据规则或参数。先复用已有3937图每图一次seed=20261012+image_id的全量增强记录，统计保留实例尺寸/类别；旧记录没有逐原始实例对应，不能从它直接分开缩放消失和裁剪损失。

补充样本按原始标注7类×4尺寸（<256、256–1024、1024–9216、≥9216）各取ID最小3张，取并集，固定selection.json；每图固定3个seed=20261012+image_id+[0,100000,200000]。同图追踪LoadAnnotations→RandomResize→RandomCrop→FilterAnnotations后的逐实例面积与保留状态，裁剪比例相对缩放后的面积计算，按原始尺寸与类别分别汇总。

临时用gt_bboxes_labels携带实例索引，Pack前恢复真实类别；所用几何变换不依赖类别值。所有样本同seed与未插桩原prepare_data逐图对照，图像、mask、labels必须精确一致（含双方None）。不改site-packages。完整验证后才能解释插桩结果。

统计原有小实例变为<16像素、<256像素、在resize/crop/filter阶段归零或移除的频率；empty负样本/裁去实例不是自动判作错误。3seed不是真实36轮曝光统计，分层便利样本不是全体发生率，不外推因果。不得据结果继续挑seed或样本。

产出：哪一环节影响小目标与类别覆盖、是否值得设计尺度/采样的单因素验证；没有明确证据则不训练。
