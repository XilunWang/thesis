# 小目标候选形状审计协议

仅本地复用baseline-query-audit-20261031的24图全部query和官方GT/原图，不训练、不推理。冻结45个全部query无IoU≥0.5的小目标，22个几何合格但低分目标作为描述性对照，不再筛选样本。

每GT选全部query中IoU最高者（并列取query索引最小），记录召回intersection/GT、精度intersection/pred、FN、FP、预测面积以及其他普通GT重叠。IoU与上一报告逐条一致。所有query均无交集时query0仅是并列代表，不能当相关预测。

描述性分组：召回<0.1为几乎没覆盖；否则FN>FP为漏涂占优，FP>FN为多涂占优，相等为混合。分组只比较像素错误数量，不证明机制。多实例覆盖线索：同一候选覆盖目标≥50%，同时覆盖至少另一普通GT≥50%；不直接命名为确定粘连，需看图及GT重叠。记录FP中落在其他GT区域的比例，未落入其他GT只称未被其他普通实例标注覆盖，不自动称真实背景。

生成全部45例及22对照的局部原图、GT和候选叠图，固定顺序分页。局部窗口可能隐藏远处多涂，保留全图指标并额外提供全图候选概览。人工观察单独记录，不调整统计阈值来获得结论。GT辅助最佳候选不代表部署可达结果；24图不是全量无偏抽样。
