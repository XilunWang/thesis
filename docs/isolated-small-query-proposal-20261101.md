# 下一候选设计：冻结原版，独立小目标补漏查询

2026-11-01。仅设计建议，未实现、未接入、未训练，不构成训练准入。不恢复BLL、MFRM或DSGAT路线，不宣称方法创新或保证AP提高。

## 为什么建议改变方式

当前直连在stride8/16共享memory中加入C3/C4投影，影响9次查询更新中的6次，并在训练中更新原模型参数。所有查询都可能受到影响，而没有“只改变某个小目标”的机制。

同预算对照中，小目标IoU0.5新增匹配24、丢24；同图L_56.jpg既恢复GT286又失去GT283。部分小珊瑚有更好的形状但分数仍低，APs增量74.6%来自水草类。支持的问题是“局部有用的变化没有与原有预测隔离”，不证明退化必然由共享memory干扰造成，原参数漂移、分类和最终筛选也可能参与。

因此下一候选不再改原解码器memory，建议先验证新增的独立读出能否补漏，同时保留原计算路径。

## 具体接法

从原始E0第36轮模型出发，不沿用已修改直连候选：

```text
图像 → 冻结的R50 → 冻结的像素解码器 → 冻结的原查询解码器
             │              │                    │
           C3/C4        mask_features        原100查询预测（保持）
             └──────┬───────┘                    │
                    ↓                            │
          新增少量独立小目标查询                   │
          独立特征投影/查询更新/类别与mask读出      │
                    ↓                            │
               补漏候选 ──────────→ 联合评分与筛选 → 最终100输出
```

原分支所有参数冻结并保持eval模式，包括归一化缓冲状态；只冻结R50不够。新增分支读取detach的C3/C4与mask_features，不反写原memory、原查询或原预测头。自己的分类和mask读出独立持有参数，可复制原头初始化，但不能共享可训练参数对象。保留原输出以检查精确一致。

新增查询数量先作为设计变量（例如20个，不是已验证最优值），使用现有stride8/16线索和原mask_features输出实例掩码；不是新增高分辨率骨干，不声称解决了mask_features分辨率上限。新增查询不依赖“原模型已经给出正确小目标框/掩码”，避免漏检位置根本无法启动修复。

## 训练职责与推理边界

设计目标是让新增分支学习原版遗漏或质量不足的小实例，不重复拟合全部大目标。只在训练时，以训练GT及冻结原版输出形成补漏监督：先按类别和掩码匹配原预测，再从原图COCO小目标标注中选出未得到可靠匹配、且增强后仍存在的目标。原图小目标标签随增强保留来源ID，不能按缩放后面积随意改换实验目标。

可靠匹配的初始可审查规则为同类mask IoU≥0.5且沿用原后处理得分≥0.5；这只是训练监督构造的候选规则，不是AP评价阈值。其阈值与重复监督风险必须在训练集验证后冻结，不允许根据验证集24例成功/失败调参。使用原分类、mask BCE、Dice监督补漏分支，不加入BLL。

在选出的残余GT中做一对一匹配，多余补漏查询监督为背景；没有残余目标的训练图片也保留，防止分支总是生成小目标。若原预测已可靠覆盖某个GT，针对该GT的额外重复候选不获得新正样本名额。需要检查原点采样损失对极小GT的覆盖，不能假定额外查询天然消除之前发现的采样问题。

推理不能使用GT或“真实漏检清单”。新增查询始终由图像特征产生，依靠训练得到的分数决定是否入选。不能用“只修错的”这种需要知道答案的规则保证正确性，也不能把低置信度等同小目标，把高置信度等同正确。

## 能保护什么，不能保证什么

可通过结构保证和测试的是：原模型的中间特征、原100查询原始输出不因新增分支训练而改变。新增分支关闭时，应精确恢复E0输出。

不能保证最终AP不下降：补漏分支仍可能误报、重复或把原正确预测挤出最终100条。原版已经输出100条，不能声称额外结果插入空闲位置；最终仍保持100条，禁止靠提高输出上限宣称收益。不先随意加NMS改变原协议。合并前后必须记录原正确输出被挤出的数量及对应新增输出是否真正有效。

因此这是限制退化来源的设计，不是零风险保证。若最终筛选无法在补漏的同时控制原正确输出损失，即使原始输出完全保留，该方案也应停止。

## 怎样验证才值得训练

1. 先完成设计及训练监督清点：仅训练集形成残余GT，列出小目标覆盖、无残余图片、重复正样本风险和极小GT采样覆盖。验证集既有案例只作诊断，不能挑案例训练或调阈值。
2. 如用户授权实现，只做无训练接入核验：关闭分支精确等价；开启分支但合并前原输出仍精确一致；新分支有梯度、原参数和缓冲状态不变；统计实际开销及最终100条竞争情况。不以随机分支产生误报判断训练后的收益。
3. 只有前两项成立才提出新的有限效果试验。主参照为同一个冻结E0；须另设同数量/同预算的“新增查询只读原融合memory”对照，避免把更多query/参数的收益都归因于C3/C4。不直接复用原全模型续训A来证明隔离分支的结构贡献。
4. 提前固定总AP、小目标AP及中大目标退化界限；类别分解与新增/丢失计数同时报告，不能再只靠小水草一类抬高APs判成功。已有+0.5总AP门槛不因当前失败而降低；新试验的全部口径、预算和种子要另行冻结并获授权。

当前不排队执行这些步骤、不建立新的长训练任务。优先审查“残余GT是否能被明确监督”和“新增输出如何通过相同100条预算”两个设计风险，避免先写大量接入代码再发现方向不成立。

## 决策状态

推荐候选是“冻结原版＋独立补漏查询”，取代继续全局注入特征；这是根据当前收益/退化证据提出的假设，不是已证明的改进。完整因果归因和同类方法检索尚未完成，不称原创或论文核心创新。模型代码和训练配置本轮均未修改。
