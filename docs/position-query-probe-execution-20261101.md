## 做了什么

沿用运行前的[机制审查与固定协议](position-query-mechanism-review-20261101.md)。E0所有参数冻结，eval模式，不创建优化器或位置头，不反传。复用同一增强图片，在第三个decoder层（首次stride8读取）临时用候选点周围3×3格替换全部100query的cross-attention允许区域；其余层恢复原流程。每个候选分别比较左/右/上/下32像素偏移；不调整窗口或位置，不融合副本预测。

原版3条路径；四目标各提示1条、偏移4条，共23条。16个偏移窗口均与对应提示窗口不同，均为有效对照。有效边缘保留与图像相交的部分格，纯padding排除。所有路径共享同图冻结特征，独立从原学习query重新计算，无跨路径状态延续。
