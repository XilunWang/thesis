# 独立BLL两次正式实验总档案

归档日期：2026-10-31。本档案把设计、验证、正式训练、结果和失败诊断串成一个入口；独立报告和原始数据继续保留。这里的“两次”是E1和E1-P两次36轮实验，E0是既有原版基线。工程检查通过不代表性能收益。

## 1. 问题与适配范围

目标是改善水下实例分割的边界，兼顾小目标，不牺牲整体和大目标精度。实际采用Mask2Former-R50独立BLL：只在训练中增加最后一层掩码的边缘区域BCE，保留原分类、mask BCE、Dice及辅助层损失。没有加入MFRM、DSGAT或独立边界头，不按旧PPT认定实现。

## 2. 两版具体差异

| 项目 | E1旧BLL | E1-P新监督 |
|---|---|---|
| 实例对应 | 最后一层Hungarian匹配 | 相同 |
| 选区 | 前一层同query预测边缘与GT边缘并集 | 相同选择思路，粗选区映射回像素 |
| 目标标签 | 原GT缩到stride4网格，4×4内有前景则整格为前景 | 增强后原GT像素，不把混合格整体标前景 |
| BCE计算 | 原生粗掩码网格 | 最终logits双线性插值到GT尺度，align_corners=False |
| 归一化 | 全批选中有效格平均 | 全批选中有效像素平均 |
| 其他设置 | BLL权重1、boundary width3，排除纯padding | 保持权重和带宽，像素级排除padding |
| 推理 | 原版结构与流程 | 相同 |

核心差异是额外损失的监督分辨率及目标表达，并非加入了更精细的预测网络。新监督可以避免粗格标签外扩偏向，但插值不等于获得新的高分辨率特征。

## 3. 第一版过程：接入、修复、训练、退化诊断

1. 完成query适配与head接入，以及数值、真实图、小规模更新和保存恢复检查。入口：[适配设计](query-bll-adaptation.md)、[接入](bll-head-integration.md)、[数值协议](bll-numerical-protocol.md)、[短试跑](bll-short-pilot-result.md)、[保存恢复](bll-checkpoint-validation.md)。历史GPU重复反传误差与原算子有关，未将其称为逐位一致。
2. 全训练数据检查发现旧缩小方式会让183个增强后非空实例消失；改用占有规则保留极小目标，并重新验收。[目标保留修订](bll-target-preservation.md)、[数据审计](bll-training-data-audit.md)。这次修复解决监督目标消失，不保证检测召回提升。
3. 固定正式协议，从COCO预训练独立训练，首轮后验收，再继续35轮。用户曾授权查看首轮测试成绩，事实保留。[训练计划](e1-bll-training-plan.md)、[首轮](e1-first-epoch-result.md)、[首轮评价](e1-epoch1-evaluation.md)。
4. 2026-10-23完成36轮70884步及691图评价，整体AP略涨、大目标AP下降。[当时训练结果](e1-final-result.md)。
5. 随后离线边界对照确认边界未改善；真实图损失和梯度检查发现混合格标成全前景的外扩偏向及局部冲突。[离线结论](e1-offline-findings.md)、[监督审计](bll-objective-audit-20261029.md)、[真实梯度](bll-real-gradient-check-20261030.md)。这是局部机制证据，不能解释全部AP变化。

## 4. 第二版过程：新监督、小目标审查、验收和正式实验

1. 比较软覆盖率与原GT像素监督，原GT候选减少了指定真实输出上的冲突，但不保证预测保留。[候选比较](bll-candidate-supervision-20261030.md)。
2. 补真实小目标，区分合理收边和前景压制；追踪两个漏涂像素，确认共享粗网格节点上背景贡献可压过前景。错误加倍、仅选错误两规则没有修复指定问题且存在其他取舍，未采用。[小目标](bll-small-foreground-check-20261030.md)、[收边与压制](bll-edge-tradeoff-20261030.md)、[两像素](bll-two-pixels-20261031.md)、[局部规则](bll-local-rules-20261031.md)。
3. 监督尺度检查显示粗网格仍有改善空间，但不能表达任意细边界；未据此直接加入局部细化。[尺度检查](bll-scale-assessment-20261031.md)。
4. 冻结PixelBLL协议并独立接入；原损失保留，helper与真实模型对照通过。[协议](bll-pixel-protocol-20261031.md)、[接入验收](bll-pixel-integration-20261031.md)。
5. 全3937张训练图每图一次固定增强：原pipeline过滤1图，其余3936图22033实例均有正监督，含6391个小面积实例。不是所有随机增强的保证。完成独立恢复验收及固定16图20步实际更新/中断恢复。[数据与恢复](bll-pixel-data-checkpoint-20261031.md)、[短试跑](pixel-bll-short-pilot-result-20261031.md)。
6. 固定正式协议，从同COCO起点独立训练，先完成首轮并停止验收，后获授权续训剩余35轮。没有从E0/E1最终权重或短试跑权重续训。[正式计划](pixel-bll-formal-plan-20261031.md)、[入口](pixel-bll-formal-entry-20261031.md)、[首轮结果](e1p-first-epoch-result-20261031.md)、[续训](e1p-resume-35epochs-20261031.md)。
7. 2026-10-31 16:37:06训练完成，16:41:35评价和三组对比全部完成。[最终结果](e1p-final-result-20261031.md)。

## 6. 后续诊断与收尾结论

[AP下降分析](e1p-ap-drop-20261031.md)：6个大机器人类别因类别宏平均对总大目标AP下降贡献约-2.997点。排序恶化与珊瑚/海底等真实几何退化并存，不是全由漏检增加或边界变化解释，其他六类平均AP也下降。

[固定案例收尾](e1p-bll-closeout-20261031.md)：三组6图1800预测精确复现；不同真阳性分别掉类别概率或mask置信度，高分误报类别过度自信；珊瑚退化在最终缩放前存在。未找到本次可确认的加载或后处理实现错误。最好IoU低分候选仅是诊断oracle，未替换正式预测。

当前建议：结束这套独立BLL主线，不再小改参数就长训；保留原版为基线及全部实验结果。这个判断不等于所有边界损失无效，也不等于发现完整训练因果。单种子、测试集曾用于设计诊断的探索性限制必须披露。其他模块仍需独立源码/接口审查，不默认携带BLL。
