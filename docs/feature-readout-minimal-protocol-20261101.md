# 冻结E0特征读出最小验证方案

日期2026-11-01。状态：缓存盘点及选样完成；仅设计，未导出特征、拟合探针或运行模型。本方案替代DiveSeg准备安排；不下载其整权重、不安装环境、不复测，也不恢复BLL/有效区域采样/邻居候选。

## 要回答什么

在已有小目标失败案例上，E0特征是否还包含能画出独立实例的信息，而实际query没读出来？将流程拆成R50→像素解码器→mask_features与Transformer查询→mask embedding→两者点积。不能将像素解码器和查询解码器混成一处，更不能强行二选一。

这是几何可读性诊断，不评价类别学习、定位泛化或AP。看过GT的探针不是可部署模块。读出成功是存在性证据；简单读出失败不能证明R50完全没有信息。

## 现有缓存能做什么

复用既有GT、分组、S0–S9全部query掩码、原尺度预测和权重身份。单凭现有缓存无法完成特征区分力验证。若执行，只需现有服务器对固定3图各做一次E0前向补取特征，不重新跑15/24/691图，不重做既有诊断；当前尚未执行该补取。

## 一次冻结前向需要补存什么

使用原E0 epoch36、既有评价配置、FP32、batch1、eval与inference_mode。保存R50的C2/C3/C4/C5、像素解码器输出mask_features、各阶段mask embedding以及必要的原始mask logits、尺寸/缩放/padding元数据。保存实际张量并记录shape/dtype/哈希，不能把上采样后的预测当特征。

所有数据都从同一次正式前向hook捕获，不能额外调用像素解码器生成另一份输出。验证embedding与mask_features点积重建原logits；复用现有报告要求核验S9的300条输出，mask变化0、分数误差不超过既有1e-4标准，记录实际误差。权重SHA53f9382f8db706be2d91da38b765b6bd5b8f26c33a2434f9a26e795fbbb8376f；无优化器、无参数梯度、前后state_dict相同。失败即停止探针。

## 最小探针：只改变读特征的向量

每个GT分别处理，原始标注像素保持不缩小，纯padding排除；相邻实例属于本实例负样本，与普通背景分开统计。GT重叠区域不能当成独占实例反例。

1. 原读出：复用S9全部query中的最佳几何，以及S0–S9最佳几何，均明确为GT oracle，不是正式检出。
2. mask_features读出：在冻结的256通道特征上拟合一个256维向量w，logits=w·F，不加偏置、不加坐标、不加新层。经原两次双线性上采样、去padding与还原原图，再以logit>0生成mask。这与原掩码输出形式一致，但w直接利用GT求解，绕过了query生成过程。
3. R50读出：分别在C2–C5上用同样的线性读出形式，经过相同原图恢复计算几何。各层通道数/分辨率不同，分开报告，不能把C5比C2分数高解释为公平容量对照，也不把多层拼接大读出当最小方案。

离线求解拟用前景/非本实例各占总权重一半的岭回归，目标+1/-1，均方误差+1e-3乘向量平方范数；各通道只按有效区RMS缩放、不减均值，保持无偏置线性表达。保留所有前景；负样本最多4096个，固定seed20261101、分相邻实例/邻近背景/远背景三组均分可用预算，缺组等分剩余；无替换抽样。邻近区定义原图GT bbox四边各扩32像素并裁至图界，只用于负采样/分组，最终不裁掉全图误报。负样本合计权重一半。用原双线性恢复对应的特征值建立设计矩阵，避免最近邻缩GT令小目标消失。

此求解是临时诊断向量拟合，不更新R50、像素解码器、Transformer、分类头或正式权重；仍必须如实称“GT辅助离线拟合”，不能称完全无拟合。岭回归不是IoU最优求解器，失败无权宣称表达上限。

## 防止把探针能力误当模型缺陷

- 首先用捕获的真实mask embedding重建已有合格案例。几何对照不能重现，说明导出/坐标/后处理有问题，停止。
- 若拟合器在已知存在合格向量的3个对照及4个早期合格案例上仍失败，登记“探针求解不足”，不再用其失败判断特征。保留实际query向量作为存在性证据，不悄悄改正则到成功。
- 每实例同预算拟合RGB三通道无偏置读出，以及独立固定随机256通道空间特征读出作为弱对照；随机特征固定seed20261101、同mask网格及相同恢复。两者不可加入特征探针，不用于选最优超参数。
- 此最小方案用目标自身GT拟合并评价，存在乐观偏差，弱对照只能揭示部分问题，不能消除过拟合。它只验证此图上能否表示，不能说明新图可泛化，也不证明训练方法已找到。
- 不调阈值、不搜索正则、不反复挑负样本、不按结果扩大案例。时间预算：补取前向不超过20分钟、离线拟合不超过30分钟；达到上限保存已完成项并报告，不自动延长或开训练。该预算是止损上限，不是耗时预测。

## 输出与判据

每GT逐行列出：原S9最佳IoU、全阶段最佳IoU、C2–C5读出IoU、mask_features读出IoU、前景召回/精度、邻居多涂像素、全图多涂像素、弱对照；另报告未抽中负像素误报，不能只在拟合点计分。成功定义全图IoU≥0.5，强改善另标比S9提升≥0.10；必须展示连续数值，不靠跨过阈值讲故事。二者只为机制筛查，不是正式AP准入。

| 观察 | 可支持的解释 | 不能声称 |
|---|---|---|
| mask_features能读出，实际全部query不能 | 最终特征存在可用线性几何，实际查询/训练未利用充分；优先考虑query形成或学习 | 已定位某层注意力错误，或换query方法必然提高AP |
| 某R50层能读出，mask_features不能 | 骨干至少该层存在可读线索，需关注像素特征转换/分辨率与求解限制 | 已证明像素解码器丢失了信息 |
| 两边均不能读出 | 现有线性探针不支持足够可读性，保持未决 | R50天生看不见，必须换骨干 |
| 两边均能读出 | 优先研究查询利用，而非凭失败输出认定骨干能力不足 | 可以直接把GT辅助读出改成推理模块 |

若只有个别成功或随机对照也接近，结论降为弱证据，不立项训练。3图结束后必须给出“支持哪一条/哪些未决”，不得自动接一串更大检查。
