# BLL候选监督：边缘冲突与小目标保留

2026-10-30。只使用已保存的4图8实例logits、匹配、GT、实际选区及原梯度，本地CPU计算。无完整模型前向、参数梯度、训练、权重更新或服务器连接；正式BLL三个核心文件哈希未变。

## 结论

两种更忠于原GT的监督均减少了此前确认的“原最终mask损失要求少涂、BLL却要求多涂”，支持继续修订占有目标。但是**保留非零标注不等于保证小目标预测保留**；两候选尚不满足可直接替换正式BLL并开训的证据要求。

优先继续检查原GT坐标监督，因为它不把小目标标注缩成一个低概率格。但它仍依赖低分辨率logits插值、正负样本分布及选区，不能保证像素级表达能力或小目标召回。覆盖率可保留为诊断参照，不能仅因冲突数更低就选为最终方案。

## 1. 两个候选如何计算

为单独检查目标表达，保持原最终匹配、原实际BLL选区、相同保存logits和名义weight1；没有重新选区或调参。

| 方式 | 标签与计算 |
|---|---|
| 当前占有目标 | 4×4只要有前景，该格目标=1，选区BCE按格平均 |
| A：软覆盖率 | 每格前景像素数/有效像素数，不做二值阈值；选区BCE仍按格平均，半格分母只计有效像素 |
| B：原GT像素监督 | logits按align_corners=False双线性插值到增强GT大小；原格选区重复展开并排除padding，直接对原二值GT算选中像素BCE |

B没有新增高分辨率特征，不等同于原Mask2Former的不确定点采样/Dice，也不等同于论文BLL。A改变了目标语义；B同时改变损失分辨率与平均单位。比较的是同一状态下的候选梯度，而不是训练成绩；不同标签下的loss绝对大小不适合直接排名。

## 3. 小目标有没有消失

必须区分两层含义：

1. **标注/正监督没有被删掉：本轮检查通过。** 122个穷举单像素位置覆盖4×4相位、有效半格和小于stride的图，两候选均保留选中正前景监督。另检查前128张原生训练图491实例，其中174个按标注面积为小目标，两候选正监督丢失数均0。
2. **模型最终一定能分出小目标：不能保证。** 4×4只有1个前景像素时，A目标为1/16。在概率0.5处梯度+0.4375，会推动概率下降；若将该软目标按0.5二值化，目标消失。B虽然保留这个像素的二值真值，但共享粗格预测可能被较多背景像素拉低，恢复原GT坐标不等于获得足够空间表达能力。

上述491实例原生图上没有观察到覆盖率按0.5阈值后整实例丢失，但不能外推到随机增强：极小合成例子已构成反例，历史183个实例丢失发生在真实增强后。122项验证是正监督存在性，不是召回或优化后预测保证。

真实4图保存输出的增强后实例面积为8166–600091像素，没有面积<1024的小目标；因此不能用它们声称已验证真实小目标预测梯度。原生128图检查没有预测、没有LSJ/裁剪，只含GT边界选区；前层预测并集不会删除这些已选区域，但会改变归一化强度。

## 4. 下一步与限制

本轮只确认候选更忠于GT并减少特定冲突，尚未选定正式修复。建议先补固定真实增强小目标的输出，检查原GT坐标监督的正/负像素贡献、有效采样和梯度强度；需要确保每个实例有正监督，但不能通过把混合格全部改回前景来掩盖问题。若改选点或权重，另立明确候选及原方案对照，不直接开36轮。

保存的4图可继续复核，但不包含真实小目标输出，这一缺口必须如实保留。用户本轮不训练，正式代码不修改。
