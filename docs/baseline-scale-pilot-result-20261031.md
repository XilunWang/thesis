# E0固定24图输入尺度对照结果（2026-10-31）

## 判断

有部分小目标恢复信号，但没有证明总体性能改善，不直接修改正式测试尺度或启动训练。全图统一放大同时增加误报，部分中大目标和共同实例的掩码精度退化。更值得下一步检查的是训练缩放/裁剪对小目标有效可见面积的影响，再决定是否需要尺度友好训练策略，不能从本结果推导重训会涨点。

## 范围与执行

按[预先固定协议](baseline-scale-pilot-protocol-20261031.md)执行。24图分别为8张含原版未形成合格掩码的极小目标图、8张其他含极小目标图、8张不含极小目标且原版背景误报较多的图。具体ID和选择原因见reports/baseline-scale-pilot-20261031/selection.json。共264个普通GT（79极小、70其他小、96中、19大）；有意选择的探索性样本，不代表691图整体分布或独立验证集。

固定E0 epoch36，原Resize长/短边约束(1333,800)，较大(2000,1200)，keep_ratio。每尺度2次预热，24图逐图交替顺序，共48次计时前向。没有更改权重、损失、类别、top100规则或分数阈值，也没有多尺度融合/NMS改造。没有优化器、反传或训练。

## 主要检出结果

分数≥0.5、同类Mask IoU≥0.5，一对一匹配，crowd按既有规则忽略。

| GT尺寸（原图面积） | GT数 | 原尺度匹配 | 较大尺度匹配 | 新增 / 丢失 |
|---|---:|---:|---:|---:|
| 极小 <16² |79|52|59|9 / 2|
| 其他小 16²–32² |70|28|36|9 / 1|
| 中 32²–96² |96|67|66|7 / 8|
| 大 ≥96² |19|14|13|0 / 1|
| 全部 |264|161|174|25 / 12|

小目标合计80→95。全尺寸误报410→439，其中背景误报363→384、定位不足31→42；不能把新增29个全尺寸误报叫“小目标新增误报”。有效预测中的匹配比例约28.20%→28.38%，基本相近，不是明显的整体精度提升。

更严格IoU0.75且score0.5时：极小27→29、其他小19→24、中48→45、大13→11，合计107→109，误报464→504。新增较宽松匹配并不都变成高精度掩码。

候选覆盖使用全部保存top100预测，不先按score0.5过滤，是GT辅助非排他统计；不等于一对一召回或AP。极小目标原来17个在任何类别都没有IoU0.5候选，其中6个放大后恢复，但又有2个原来有候选的丢失，任意类别覆盖62→66。小目标中的改善更明显出现在面积16²–32²组；不能称极小目标候选不足已解决。

## 下一步建议

只读审计原正式训练增强在不同随机尺度下，极小/其他小目标缩后面积、被裁去比例和有效训练出现次数，与类别同时统计；优先复用既有数据审计，不为补充假设再次开长训。原LSJ范围0.1–2.0，可能改变可见性，但此处未证明它是原因。若缩小/裁剪确实系统性损害小目标，再冻结单因素、带中大目标与误报约束的尺度/采样对照计划。不能将输入放大的一次试验直接变成训练策略有效的结论。

本轮无模块开发，MFRM暂停、BLL结束；研究继续由原版问题证据驱动。
