# 原版训练匹配分工审计协议

仅用训练集。复用已有3937图固定增强记录，按7类各取增强后有面积<1024非空实例的最小2个图像ID，去重并冻结selection.json。不根据模型表现选图。重现seed=20261012+image_id原增强，与旧记录的GT面积/类别逐项核对；固定E0 epoch36、原训练数据预处理、batch1，不声称重放历史batch2训练轨迹。

模型训练模式、原norm_eval设置；只运行前向和最后层原_get_targets_single，不执行loss backward、optimizer或参数更新。每图同一前向，用3组固定匹配点种子20261031+image_id+[0,100000,200000]检查随机点敏感性。主结果只取offset0，其余做稳健性描述，不挑seed。

临时包装原assigner捕获同一批采样点计算的分类/BCE/Dice加权代价及分配，仍调用原assign方法；同RNG下移除包装重跑原target函数，分配与标签、mask targets应精确一致。独立重算总代价的匈牙利结果须一致，各GT正常有一个正样本时核验覆盖。

同一增强后GT网格，全部query经原双线性上采样、logit>0得到完整几何IoU，不用采样点IoU冒充完整几何。每GT比较几何最佳query与实际正样本：前者是本GT正样本/其他GT正样本/无目标，是否存在best IoU≥0.5而实际正样本<0.5，记录差值≥0.1及代价组成。正样本本来就不是逐GT独立最大IoU，未匹配的好候选可能只是正常重复预测，不能据此判bug。

检查每GT采样前景点数和3seed分配变动；不把一次匹配反推36轮历史、不改匹配权重、不改训练标注或开训。若匹配正常或没有明确不利关系，不扩展该机制猜测，归档局限。
