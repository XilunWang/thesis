# 小目标候选位置选择协议

2026-11-01。承接独立位置头无更新验收。本步明确选点、预算和近邻保护，完成离线参考实现；没有训练、服务器运行、query解码或最终结果合并。旧文献方案中的“空间分散”在本协议中明确不采用硬距离排斥。

## 1. 怎样选位置

输入是独立位置头的stride8单通道logit图，以及增强/推理预处理记录的有效图像尺寸。每个格子代表一个候选种子位置，不是已经识别出的实例。

1. 排除完全处于padding的格子；与有效图像相交的边缘格保留，和监督口径一致。
2. 所有有效格按logit从高到低排序。sigmoid单调，排序不必转换概率；这些分数尚未校准，不能解释成准确率。
3. 同分按格子行优先编号从小到大排序，保证可复现；有效格有NaN/Inf就报错。padding的非有限值不参与排序。
4. 取前`min(K, 有效格数)`个不同格。**不设0.5阈值、不做局部极大值筛选、不做距离NMS、不要求候选彼此远离，也不先按原版预测删位置。**
5. 候选坐标取该格与有效图像相交区域的中心，除以有效宽高得到归一化坐标。边缘坐标不会落进padding。此中心不保证落在真实mask内；这是位置参考，不是GT前景像素定位。将来gather内容使用对应stride8格；跨层坐标映射另需在query接口中对齐，当前未实现。

推理仅使用图像分数和有效尺寸，不使用GT实例数量、类别、面积、边界或占据格分配。无小目标图片仍会取满预算，这是固定候选池，不是最终检测；未来实例分类/无目标分数应承担拒绝候选的职责。

## 2. 选多少

**下一阶段位置学习检查的主预算固定K=100**；同一张排序图同时统计K=20、50、100、200，不额外训练四个模型，不根据验证集成绩临时切换主预算。

100是有限预算下的阶段性比较点，便于与原模型100查询规模对照，并非已证明足够或最优。候选池、实际新增解码query和最终输出是三个不同数量：本协议只固定位置候选池；完整实例分支的query数须结合定位收益和实测开销另定，不能把200点诊断自动变成200个新增query。正式AP仍保持原来的最终100输出。

依据是已封存的固定6图12次增强，其中1次原pipeline过滤、11份有效样本，10份含小目标。这批图按密集目标选取，不能代表全训练集分布。1076条是增强实例记录，同一GT可在两次增强中重复。

|候选预算K|假定排序完美时最多覆盖|占1076条的比例|小目标数超过预算的有效样本|
|---:|---:|---:|---:|
|20|200|18.6%|10/11|
|50|500|46.5%|10/11|
|100|922|85.7%|4/11|
|200|1076|100%|0/11|

这是`sum(min(K, 每图小目标数))`的**数量上限**，通过GT正格置高分的参考排序复核，不是模型召回、AP或残余漏检数量。K100在这批样本即使完美也至少漏154条；不据此宣称100可以找全。K200只用来区分排名靠后与数量截断。如果只有放大到200才有覆盖而K100无优势，应先重审预算/分数区分能力，不能直接进入重型实例解码。

## 3. 怎样保护相邻小目标

训练端沿用已验收的一实例一占据格分配：只有某实例实际占据的格才可分给它；同格冲突通过重新分配解决，分配失败明确报错，不合并标签、不偷偷丢GT。本协议不增加槽位。

选点端允许相邻格同时入选。例如两个相邻格分数0.9和0.8，二者均排入前100时都保留；不会因为0.8不是3×3邻域最大值而删掉它。不做连通域合并，也不强制空间均匀配额，避免密集区域被限额。

这只防止**选点算法主动吞掉邻居**，不能保证网络会画出两个峰、两个目标都进入top100，也不能保证未来mask不会粘连。单个目标可能产生多个高分格，消耗名额。当前不靠距离去重掩盖这个问题，而是将重复占位与漏目标一起报告。若两个极小实例实际只占同一个stride8格，单槽位无法表达，现有报错必须保留；固定样本全部可分配不等于全训练集可分配。

## 4. 怎样判断位置头有没有用

未来获得学习授权后，在预先固定的训练内留出图上验收，不用691张官方评价集反复选预算/阈值；当前密集6图仅作工程验收，不能当泛化证据。主指标和辅助指标必须一起报告：

- **种子召回R@K**：选中已确定监督正格的实例数/原小目标实例数。直接检查监督是否学到，不以一个位置同时命中多个GT。
- **占据格召回R@K**：候选格与GT“该格有任意前景像素”的关系做最大一对一匹配。它容许位置落在同实例其他格，避免只按唯一种子低估；但只是宽松几何机会，不是中心点落在mask内，更不是正确分割。
- **候选利用率**：上述一对一匹配数/实际候选数。分别记录完全不接触任何小GT的格、接触小GT但无法增加一对一匹配数的冗余格；后者不全部武断归因为同实例重复，重叠GT/匹配竞争也可能造成。
- **近邻成对保留率**：以已分配种子格切比雪夫距离≤1的实例对为固定近邻集合，统计两枚种子同时入选比例；另报原代表格有冲突的GT子集。前者是选点尺度的近邻定义，不冒充所有物理相邻目标。类间/同类分开列。
- 同时报告每图数量上限`min(K,N)`、达到上限的比例、鱼/珊瑚/其他类别、密集/非密集、空小目标图片。没有小GT的图不定义召回，但保留候选数和分数统计。

主对照为**相同有效格、相同K的均匀无放回选点**，固定随机种子并重复统计；学习头必须显示比无图像依据的选点更有用。评估中GT只计算指标，不帮助候选排序。相同K比较位置质量；K曲线揭示预算敏感性，不能混用较大K宣称位置机制有效。

当前没有训练后的位置分数，不能给真实召回或通过收益门槛。下一项应形成一次有明确训练内留出、固定计算预算及通过/停止标准的位置头可学习性试验计划；获授权后仅学习此头。暂不实现完整新mask解码器、不再扩大GT几何小测、不启动3轮或36轮全模型训练。
