# E1本地离线对照结论

2026-10-23，691张图，3748个普通GT，保留官方划分与重复图。无训练、无服务器连接、无重新推理。

## 主要结果

- 固定score≥0.5、同类Mask IoU≥0.5：小目标未匹配539→539，中目标367→382，大目标333→311。大目标并非该阈值下漏检增加；小目标AP上涨也不能称漏检减少。0.7阈值大目标未匹配390→407，方向对分数敏感。
- 两版共同匹配的871/1239个大目标（覆盖70.3%），边界IoU70.63%→69.64%，552下降、319提高；Mask IoU87.95%→87.70%。边界为图像对角线2%内部带，不是Boundary AP，结论限于共同匹配集合。
- 共同大目标按GT面积归一的多涂比例8.04%→9.12%，漏涂5.96%→5.30%，提示输出平均更外扩；不能证明由块占有规则、损失权重或带宽中的哪一项造成。
- COCO大目标AP主要负向类别差值：机器人-9.31点（仅6个大GT）、潜水员-5.96、水草-3.53；沉船/遗迹+11.24。类别等权，不按实例数加权。IoU0.95大目标AP下降4.56点；平均大目标AR反而上升1.79点。不是召回全面下降。
- 大目标新增未匹配35个、找回57个；新增35个中32个存在同类IoU≥0.5的低分候选。极端退化案例存在完整低分掩码和缺块高分掩码并存，说明排序也参与实际输出退化。
- 探索性GT oracle：同一871个GT中，不设分数门槛、不要求一对一，仅选已保存同类Mask IoU最高候选，Mask IoU90.08%→90.26%，边界IoU72.94%→72.55%，候选平均分0.656→0.577。使用答案的诊断，不能部署、不能替换主指标，不能当严格AP原因分解。

## 结论与决策

本次BLL整体AP略增，但没有达到预期的大目标边界改善目标，不应直接当成功边界模块叠入组合。已定位到边界质量、类别差异和分数排序等退化表现；尚不能证明BLL内部哪项设计是原因，也未排除单种子随机差异。暂不新增训练，先据此决定是否值得提出独立修订假设。

本地重算COCO与原报告按三位小数一致；未舍入整体AP32.6222→32.9595（+0.3372点），大目标47.7696→46.5519（-1.2176）。以往32.6→33.0的+0.4是展示值差，保留历史但以本次精确复算为准。
