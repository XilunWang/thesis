# 原GT像素监督：合理收边还是压制前景

2026-10-30，仅复用已保存ID7/22/23的4个小目标输出，本地计算。没有服务器连接、模型前向、参数/输出更新或训练；正式BLL不变。

## 判断

当前候选在本样本中主要兼顾收边与补漏，并非普遍压制小目标；仍有一个实例的2个漏涂像素被推向更低前景值。**暂不统一提高前景权重或替换为前景/背景各半。** 各半候选没有解决这2个像素，却使更多多涂背景朝错误方向移动。继续原GT像素监督的验证，但不能宣布已得到正式修复。

## 固定口径

仅检查旧BLL选区展开后的有效像素，保持GT、query匹配及保存的E1 logits不变。先在当前插值logits以0（概率0.5）划分四组：漏涂前景FN、正确前景TP、多涂背景FP、正确背景TN。该二值阈值只用于冻结诊断分组，不改变模型推理或AP规则。

对照两个固定公式，不搜索权重：

- 当前原GT像素候选：所有选中像素BCE平均。
- 诊断平衡候选：每实例0.5×前景BCE均值 + 0.5×背景BCE均值。其前景像素相对背景像素权重分别提高1.89/2.11/3.17/4.78倍，不能理解为固定前景乘2。

为只比较方向，把每实例原生logit梯度归一为单位L2范数，再用双线性插值算其负方向在各组像素上的作用。**没有实际修改logits，也没有optimizer.step**。原候选在实际全批全选区平均；本诊断逐实例平均仅改变该实例正尺度，单位范数后方向相同。平衡候选仅诊断实例内部前景/背景分配，没有验证跨实例归一化或模型参数更新。

前景方向向上、背景方向向下视为朝GT正确方向；反向不等于已造成阈值翻转。尤其TP概率下降不能直接叫“伤害目标”，因为仍可能正确且有助于收边。

## 结果

| 固定像素组 | 像素数 | 当前候选朝正确方向 / 反向 | 平衡候选朝正确方向 / 反向 |
|---|---:|---:|---:|
| 漏涂前景FN | 179 | 177 / 2 | 177 / 2 |
| 多涂背景FP | 1644 | 1638 / 6 | 1629 / 15 |
| 已正确前景TP | 1810 | 781 / 1029 | 905 / 905 |
| 已正确背景TN | 4143 | 3496 / 647 | 3370 / 773 |

前两行直接检查已有错误是否被推向修正；后两行只是正确像素置信方向，不能将所有反向项称为新增错误。没有任何新预测/召回/AP结果。

单位梯度下，FN平均正确方向作用0.0951→0.1878，但FP平均正确方向作用0.1348→0.1107。即平衡增强了部分补漏力度，同时减弱收边；不能仅凭某个方向的强度增加宣布更好。

### 回看上轮“GT均值被压低”的两个实例

- ID7/query38：GT537像素，仅2个当前漏涂，选区有414个多涂背景。当前候选能压低全部414个多涂背景，但也压低那2个漏涂前景；平衡后仍是这2个方向错误，虽然平均错误方向幅度减小。说明合理收边与局部不利影响可以同时存在。
- ID22/query84：GT326像素，2个当前漏涂、135个多涂背景。当前候选提高2个漏涂像素、压低133个多涂背景。其整个GT平均值下降，不能解读为“正在把小目标抹掉”。
- 另外两个目标的88/87个漏涂像素均被当前候选推动提高。

本轮没有将背景分支单独归因为所有反向结果；分析的是候选前景+背景合计后的方向。此前分项分析与本轮分组结合，支持区分平均收缩与局部漏涂，但不能证明网络训练后的实际行为。

## 决策和下一步

保留当前原GT像素候选，不正式修改权重。优先定位ID7/query38两个漏涂像素的几何位置、原生网格共享及周围背景，而不是全局加大前景惩罚。再用更多固定真实小目标及更小尺度验证，必要时比较局部选点或监督尺度方案，同时记录收边代价。四实例不足以选择正式超参数或证明召回安全。
