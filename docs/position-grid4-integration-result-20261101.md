# grid4-v1修订完成：384份缓存与3张真实图无更新验收通过

2026-11-01。按用户授权实现4×4细网格，同步标签、valid区域及选点坐标，复用原192张图384次固定增强。**本次没有optimizer.step或训练，原E0没有改变。**

## 实际改动

新增独立模块`scripts/position_grid4.py`，表示版本`grid4-v1`。保留旧`isolated_position_head.py`、旧stride8选点脚本与失败报告，旧计划仍不能直接执行。

- 新头继承原C3/C4 detach、通道归一化、128通道投影、尺度融合和stride8的3×3卷积，只把最后1×1卷积从1通道换为4通道，随后PixelShuffle(2)。通道顺序为左上、右上、左下、右下；每个子格独立预测分数，不复制单个旧分数。
- 参数344577→344964，增加387。输入1024²时logit为256²。原R50和Mask2Former分支不接收该头输出。
- 新标签函数在stride4上根据真实GT占据格做一对一最大匹配；原始面积、实例ID、mask及正负均值BCE不变。仍明确拒绝无法分配的实例，不静默删目标。
- 新选点函数按stride4有效格排序，保持K100、同分行优先、无阈值/NMS；返回格子与有效图交集中心的归一化坐标。完全padding排除，部分边缘格保留。此坐标是位置参考，不保证落在前景像素内。
