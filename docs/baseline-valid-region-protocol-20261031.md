# 有效图像区域匹配采样对照协议

冻结上一轮12训练图、70GT、原增强seed、E0 epoch36及3组匹配seed，不挑样本或结果。每图同一前向同时比较：原整1024画布均匀点；相同基础随机点按有效图像宽高/画布宽高缩放后得到的有效区域均匀点。都是12544点，不按GT选点，不改分类/BCE/Dice成本、权重、匈牙利分配、GT或模型。

原组必须精确复现上一轮增强、预测RLE、分类概率、三seed分配和成本；独立采样计算复现原_get_targets_single结果。无padding图有效区域与原组成本/分配逐位一致。GT有效区域外必须全零。保存两组采样前景点数和完整成本/分配，独立重算匈牙利；状态/权重不变，无优化器、反传和更新。

主结果只取第一seed，另外两组看稳定性。用增强后完整画布IoU对照正样本几何（小/非小分别报告），统计≥0.5获得/丢失、均值、明显升降≥0.1、前景采样全零、三seed负责query变化。保留具体退化，不能只报平均。匹配变化并非模型预测改善，不能称召回/AP提升；GT最佳候选只是参考。

若前景采样增加但分配没有改善或出现明显新退化，不直接接入/开训；对照通过也只支持后续技术检查。原始全图匹配数据和所有失败保留，用户负责Git推送。
