## 检查方法

入口 `scripts/audit-uiis-bll-data.py`，在服务器现有 MMDetection 环境使用 CPU 执行。读取正式 E1 配置中的真实训练 pipeline 和 data_preprocessor：原 LSJ 缩放、翻转、裁剪、标注过滤、归一化及 1024×1024 padding。官方训练集 3937 个图片 ID 必须全部出现且不重复；不使用失败后自动换图的 refetch。

每图使用 `20261012 + image_id` 固定种子，按 ID 排序、每批 2 图，最后 1 图保留。逐图记录文件哈希、增强信息、实例数、标签、掩码像素数和缩小后像素数。检查输入有限值、尺寸、类别范围、二值掩码、padding 零值和框的有限性。通过与正式候选相同的 nearest 规则从 1024×1024 缩至 256×256，并排除 padding 和边缘不完整网格，统计非空目标变空的情况。

这覆盖每张训练图的一次增强，不是正式 Runner 第一轮的随机顺序，不穷尽所有增强。检查的是被真实 pipeline 接受并处理的标注，不是对每条原始 polygon 几何正确性的重新审计。没有预测、Hungarian 匹配或预测/GT 边界并集，因此不评价匹配后实际损失、完整边界选区和 AP。
