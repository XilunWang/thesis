# BLL监督区域、标注缩小与损失核查

2026-10-29。本地运行生产helper及独立NumPy公式对照，不构建模型或优化器、不更新权重、不训练、不连接服务器。当前三个训练核心源码SHA256与E1保存的run-protocol.json一致；未修改算法。

## 结论与证据边界

当前最有依据的问题是：**为防止小目标消失，BLL把混合前景/背景的小格整格标为前景，再在边缘选区对它施加强监督，形成向外扩的偏向。** 本轮验证了这个目标确实影响BLL的偏好，而不只是画出来显得粗。

另确认监督区域不是均匀边界带，全批像素平均会改变实例之间的权重。没有发现本次测试能确认的公式、梯度正负号、实例配对或padding错误。以上是生产helper的性质，尚不能证明哪个因素导致了实际36轮训练的多少退化。真实训练增强下的两层logits和完整模型梯度仍缺失，不能写成“最终原因全部查清”。

## 1. 标注缩小：保留实例不等于保留边界精度

正式BLL是stride4占有目标：4×4内只要有一个前景像素，该格就为1。此前128张训练图491实例的原生分辨率审查已确认大目标展开面积总计增加5.87%，详见[bll-design-review.md](bll-design-review.md)；这不是本轮重算，也不是训练增强分布或最终输出面积增幅。

本轮构造跨格对齐的矩形，固定同一监督区域240格，其中44格是前景/背景混合格。分别输入两组**人工构造的概率**：占有目标对应前景0.95/背景0.05；按真实块内前景覆盖率构造概率并截断到[0.05,0.95]。

| 人工预测倾向 | 实际生产BLL |
|---|---:|
| 边缘有一点前景就整格高概率 | 0.051293 |
| 按块内真实前景占比表达 | 0.195611 |

BLL给前者更低的惩罚。这是目标定义导致的可验证偏好，不是网络输出实验。覆盖率只是诊断参照，不能直接当作正确的最终预测、原Mask2Former点采样损失或已验证替换方案；模型推理插值也不等同于把网格重复展开。

## 2. 监督区域：不一定包含物体外侧

源码的boundary用7×7邻域：中心二值值乘49减邻域总和，绝对值大于7.35才选中。它不是“沿轮廓均匀画一圈”，其选择随局部形状和大小变化。

在64×64网格、上一层全背景、物体远离画布边缘的受控例子中：

| 正方形边长（网格格数） | 被选前景格 | 被选背景格 |
|---|---:|---:|
| 1 | 1 | 0 |
| 2 | 4 | 0 |
| 3 | 9 | 16 |
| 8 | 52 | 68 |
| 20 | 148 | 164 |

极小物体的这个场景只获得“里面应是物体”的BLL监督，周围背景没有被GT边界分支选中。并非没有任何背景监督：原mask损失仍保留，上一层预测边界也可能补充区域。不能据此认定真实训练的小目标都缺少外侧监督，也不能把它单独解释为大目标下降的原因。

另一个受控例子给上一层添加远离GT的错误块，选区从240增至299格，多出59个背景格。**这些格的标签仍来自GT，BLL推动它们变成背景，并没有把上一层错误当真值。** 但全局平均使原240格各自的梯度缩为原来的240/299=80.27%。因此前层预测会改变监督分布，即使loss数值几乎不变（全零logits时均为约0.693147）。

## 3. 损失计算：公式正确不意味着研究设计有效

本轮以独立NumPy实现逐格核对生产函数：块最大值、7×7选区、稳定BCE、全部最终logit梯度，以及有效边缘半格/padding、query与GT配对置换，均通过。前层硬选区无直接梯度；最终logit的梯度符合：

`(sigmoid(logit) - 占有目标) × 是否被选中 / 全批选中格数`

正式权重为1。梯度符号没有反：目标1推动概率升高，目标0推动概率降低。原模型最终层分类、mask BCE、Dice及各辅助层损失都保留，BLL是额外项，不是独立边界分类头。

全批像素平均意味着每个实例并非等权。在同一批人工输入、所有logits=0时，单格小物体选1格，20×20物体选312格，二者对最终logits的绝对梯度和分别约0.001597和0.498403，相差312倍。**这不是网络参数梯度之比，也不能外推所有大目标都会支配训练**；它验证的是选区数量会影响额外监督分配，不能只看名义权重1认为影响小。

## 4. 如何解释边界变差，下一步怎样验证

已有预测中，多涂增加与边界下降共现；本轮确认目标确实鼓励混合边缘格提高前景概率，二者方向一致。因此优先调查“占有目标外扩 + 额外边缘BCE”是有证据的判断。但仅凭这些结果，无法排除前层选区、归一化、带宽、分类排序及单种子波动，也无法证明完整模型原损失与BLL发生梯度冲突。

下一步最小验证：在现有完整框架环境加载已保存E1权重，固定训练图，导出真实增强GT、最终原匹配、前后层logits、实际选区；只计算原最终层mask损失与BLL各自的梯度及目标分歧，不执行optimizer.step。当前本地没有所需框架和中间张量，本轮未完成这个模型级验证，也未连接服务器。不直接恢复nearest、不改weight/width、不启动新训练。
