# 辅助query接入合同与设计阶段投入判断

2026-11-01。完成目标对应、隔离、损失、对照与退出条件的统一说明。本文件是待实施技术合同，不是已通过的模型验收；没有新增head、训练入口、模型前向或参数更新。

## 本轮明确决策

技术上有可描述的接入路径；研究上，当前“单格邻居干扰”仍不足以支持投入模型开发和GPU训练。建议暂缓该具体候选，保留代码/数据/方案，不再继续为它拆分几何小测、扩样或调噪声参数。并非证明所有实例引导方法无效，也不自动切回局部细化、BLL或有效区域采样。

原因：最小规则目前只在2图3对目标上证明可构造；原始164图邻接覆盖说明场景存在，不说明模型错误由该机制导致；原MP已经包含引导训练，新增差异目前只是干扰来源和支持条件，尚无普通query获益证据，也未形成可主张的研究贡献。为了验证它需要原版、参考、匹配预算扰动等多个对照，不能用一次候选涨分跳过这些成本。

## 1. 目标与query对应

普通分支保留100个learned query及原Hungarian分配。辅助分支每个增强后有效GT最多1个query，按GT顺序固定aux_to_gt映射；不得因为同一个目标有两个邻居就重复增加它的辅助query或监督权重。

邻居在原增强像素空间按同类、非重叠、距离≤32、至少一方小目标的既定条件选择，取距离最近者；同距按增强后GT索引。选择发生在尺度检查前；某层不满足条件不能换另一个邻居直到成功。该一目标一邻居方案是拟定的网络接入规则，本地此前逐对枚举并未验证其全批行为，不宣称新数字。

辅助query的GT类别提示、标签噪声、位置提示、重复组数及初始化必须在参考/对照/候选之间相同，不能在候选中暗加位置编码解决身份歧义。若最终固定原MP示例应明确其mask noise0、label noise0.2等具体设置；未固定上游commit和完整复现前不能宣布“原MP已复现”。

## 2. 精确接入位置和数据流

当前MMDetection3.3.0的Mask2FormerHead.forward在pixel_decoder后构造query_feat/query_embed，循环9次调用decoder.layers[i]，_forward_head共同预测类别及mask。拟在训练路径中拼接[辅助P个,普通100个]，使用相同decoder与cls/mask头；每层输出拆回两支，普通支独立进入原loss。推理不构造辅助query，不读取GT，直接走原100query路径。

只读核对的固定上游：[mask2former_layers.py](https://github.com/open-mmlab/mmdetection/blob/v3.3.0/mmdet/models/layers/transformer/mask2former_layers.py)。layer已有self_attn_mask及cross_attn_mask参数，先cross再self；无需为了支持这两个mask先改注意力算子。当前head需显式传新增self mask，不能把训练GT门替换普通100query的预测门。

cross mask形状按batch/head/query/memory对齐；普通部分仍来自原预测，辅助部分按对应GT构造或条件规则处理。stride32/16/8条件逐层判定，回退是辅助原支持，不是把GT门传给普通query或删除训练目标。选择细尺度不等于新建高分辨率分支。

## 3. 防泄漏与padding

self-attention布尔mask中True表示禁止。必须在所有层阻断普通query行读取辅助query列。即使普通输出最后不包含辅助query，只要中间读过GT引导特征，仍存在泄漏。

辅助分支是否读取普通分支、同组其他辅助query，需跟固定参考实现保持一致并在三个辅助组中完全一致，不能只给候选更强隔离再称仅干扰来源不同。批内padding槽位不参与损失，所有真实query不得读取无效槽位。有效/空GT/padding行必须避免所有key被禁导致NaN；无GT批次回到原路径。相关逻辑尚未实现或验收，不能只靠query_key_padding_mask字段名猜测生效，需按具体layer参数检查。

关闭辅助分支时应严格返回原父类路径；推理输出与原模型同权重一致才算接口通过。训练时共享参数接受辅助梯度是预期作用，不能称原模型学习不受影响。

## 4. 损失与身份

[MP-Former criterion](https://github.com/IDEA-Research/MP-Former/blob/main/mask2former/modeling/criterion.py)将普通匹配与已知索引辅助损失分开处理。拟采用相同原则：普通分支原分类/mask/Dice及辅助层监督保留；辅助分支直接使用aux_to_gt，不另跑Hungarian，不把普通重复query都当正样本。

GT必须保持原实例身份；修改的是训练注意力允许区域，不是把邻居GT并入标签。分母按有效目标/重复组规则固定，不能按“本批多少目标成功加干扰”重新缩放损失，否则候选的权重随覆盖变化。

批内同类辅助query如果输入和全部可用空间提示相同、却要求不同GT，需明确记录。已有逐对门不同并不保证整个batch都没有这种歧义。候选造成的新碰撞应与对照共同回退；原参考本身的粗尺度碰撞不能被回退说成已修好。这也是目前不能宣称完整模型可行的原因。

## 5. 公平对照的最低要求

| 组别 | 用途 | 差异约束 |
|---|---|---|
| 原版同预算 | 判断额外训练本身 | 不含辅助分支 |
| 固定MP式参考 | 判断已有引导机制 | 版本和所选变体明确，不混淆论文/脚本默认 |
| 配对未标注格对照 | 排除任意额外干扰 | 与候选相同辅助query、对应目标、支持条件、标签噪声、损失与预算 |
| 配对邻居格候选 | 检验邻居来源价值 | 对照/候选每次同加1格、同切比雪夫距离，同步回退 |

未标注格不是已证实背景；距离/格数一致不控制方向、纹理和颜色，结果不能证明所有语义因果。原MP参考与新配对对照不是一回事，不省掉参考后宣称超越已有方法。

所有真正效果评价只能使用普通query、正常无GT推理和同一官方691图AP，报告小/中/大及各类负向变化。辅助分支在GT提示下更准不作为效果结论。不能将此次训练机制的效果直接与E0旧结果相比而省掉同预算原版。

## 后续如何避免重复循环

保留E0和已有负结果，不把新候选名称当进展。只有出现明确的新机制、与已有方法可区分且针对本项目问题的证据，才重新讨论实验投入；不能将“规则能够生成”升级成“值得训练”。若用户另行选择复现强方法作为性能对照，应清楚标记为已有方法复现，单独确定算力预算，不冒充原创研究，也不把本文件当训练授权。
