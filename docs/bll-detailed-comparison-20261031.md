# BLL两组与三组详细对比（2026-10-31）

所有数值来自已完成的36轮最终权重、同一官方691图测试集。AP均按0–100显示；IoU、多涂/漏涂按百分比显示；差值使用未舍入原值计算，单位为点（百分比指标为百分点）。没有重训或重新推理。

固定诊断：score≥0.5，同类Mask IoU≥0.5、一对一匹配；边界带宽为图像对角线的2%。边界及几何表只比较同一批共同检出的GT，非Boundary AP。漏涂=GT内未预测像素/GT面积；多涂=GT外预测像素/GT面积；先逐实例算再平均，数值不互补，多涂可超过100%。漏检是该阈值下未匹配GT，不等于没有任何预测。

小目标面积<32²，中目标32²至96²，大目标≥96²用于固定诊断。COCO AP使用官方实现的面积区间端点规则；不要以自定义尺寸重新计算AP。

## 使用说明与结论

两组共同2384个目标（大871），三组共同2323个（大846），因此两张几何表中的原版/旧BLL数值也会变化。这不是评价规则变化，而是共同样本集合变化；只能在同一张几何表横向比较。AP与全体GT漏检表不受共同集合变化影响。

旧BLL整体AP略涨，但共同目标边界下降、多涂增加；新监督相对旧BLL减少多涂、改善部分边界，同时漏涂增加，AP与大目标AP下降。新监督边界仍未超过原版，不能称有效改进。一次训练/单种子，不代表稳定性证明。
