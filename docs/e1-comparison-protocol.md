# E0/E1离线诊断协议

2026-10-23，在读取本次诊断结果前固定。仅使用两组epoch36预测和官方691图标注，不训练、不重新推理、不改阈值选择结论。

1. 重算COCO segm评价，按原maxDets=[100,300,1000]（从实际评价配置核实），报告全部/大目标每类AP和各IoU阈值AP/AR，验证与原报告取三位小数一致。移除预测bbox字段后loadRes，防止按框面积划分mask预测尺寸。
2. 沿用既有score>=0.5、同类Mask IoU>=0.5、置信度降序一对一最高IoU匹配；0.3/0.7仅作为预定阈值敏感性对照，不选最优。普通GT漏检与crowd忽略按既有脚本。尺寸互斥small<1024、medium<9216、large其余；COCO边界值口径单列说明。
3. 原分辨率，边界带为图像对角线2%，3x3核腐蚀d次且图外背景；两组各自匹配均值与共同GT配对均值均报告，后者按同一GT ID比较，不按边界重新挑匹配；列覆盖率和边界/掩码变化。不是Boundary AP。
4. 对新增漏检按已存预测诊断：同类IoU>=0.5但score<0.5、被一对一匹配竞争、仅错类IoU>=0.5、同类最大IoU在[0.1,0.5)、无足够重合，按此前顺序单一归类。这是证据标签，不是模型因果或TIDE AP归因，不能判断不存在于预测文件中的候选。
5. 可视化预定选择：共同匹配大目标边界下降最多2例、上升最多1例、变化最小1例，以及新增漏检中原版IoU最高2例；按GT ID打破并列。不用案例数量推断总体比例，不把全图诊断误当局部因果解释。

本次单种子，仅能确定性能变化体现在哪些类别和实例，不能从输出反推BLL内部哪一项造成变化。原测试集提前查看事实及官方重复图保留。
