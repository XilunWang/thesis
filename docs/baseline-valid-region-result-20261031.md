# 有效区域匹配采样对照结果（2026-10-31）

判断：小规模机制对照出现明确正向信号，值得准备独立开关和接入验收；还不能宣布AP提升或启动正式训练。原版模型、预测、GT均未改，只比较固定前向下训练匹配点的位置。

## 比较了什么

按[冻结协议](baseline-valid-region-protocol-20261031.md)，沿用12张训练图、70GT（32小/38非小）、原增强种子、E0 epoch36及3组匹配种子。每图同一次前向，各组都是12544点，分类/BCE/Dice成本权重和匈牙利算法相同。

原组：在补齐后的1024×1024画布均匀采点。候选组：将完全相同的基础随机坐标乘以有效宽高/画布宽高，均匀覆盖真实图像区域，不按GT或预测选点、不增加点数。仅改匹配采样；原mask损失采样未改，本轮未计算损失或反传。

原组精确复现上轮增强GT、全部query的原图RLE、分类概率、三seed成本与分配；独立采样实现与原_get_targets_single精确对照。无padding的4张图（8/12/18/365），候选与原组全部成本和分配精确一致。有效区外GT全零、两组每GT有唯一正样本、独立匈牙利重算均通过。状态/权重不变，无优化器、梯度或更新，下载哈希及本地RLE重算通过。运行结束GPU占用0 MiB，没有关机。

## 小目标结果

“合格”指分配的正样本在增强后完整画布上的mask IoU≥0.5。只是匹配分工指标，不是模型召回或AP。

| 32个小目标 | 主seed：原→有效区 | 第二seed：原→有效区 | 第三seed：原→有效区 |
|---|---:|---:|---:|
| 分配到合格正样本 | 23→24 | 22→24 | 23→24 |
| 平均正样本IoU | 0.5637→0.6028 | 0.5799→0.6033 | 0.5634→0.6032 |
| GT前景采样点全零 | 3→1 | 4→1 | 2→1 |
| 新增合格 / 丢失合格 | 1 / 0 | 2 / 0 | 1 / 0 |
| IoU增加至少0.1 / 降低至少0.1 | 3 / 0 | 1 / 0 | 2 / 0 |

三seed之间负责query变化的小目标从12个降到1个。全部query中原本只有24个小GT具有合格几何，候选在每组都为这24个分配到了合格正样本；不能创造其余8个不存在的好候选。

仍有轻微退化，不能称处处提升：主seed有3例IoU下降（图613/index3约-0.0532、620/index7约-0.0144、558/index2约-0.0136）；第二seed1例约-0.0051；第三seed3例，最差仍约-0.0532。均未让原来合格的目标跌破0.5。编号index为增强后GT的0起始索引。

38个非小目标三组的负责query全部不变，合格数均为32，平均IoU均为0.7460，没有本轮观察到的非小目标退化。样本很小且来自固定便利选图，不能承诺其他图、其他权重阶段也如此。

图620有效图像164×164，补到1024×1024；index3目标106像素。权重和全部query输出一致：

| 采样组 | 原前景点→有效区前景点 | 原负责query IoU→有效区负责query IoU |
|---|---:|---:|
| 主seed | 0→73 | 0.000→0.652 |
| 第二seed | 0→73 | 0.000→0.667 |
| 第三seed | 2→55 | 0.623→0.664 |

候选组各seed选到query9/19/17，语义分工仍有细微变化，但几何均合格。三个query的正确类别概率仍约0.002，修改匹配没有立即让预测获得高分；是否能通过训练改善分类，尚未验证。

仍然全零采样的是图12/index1的27像素目标，图片没有padding，两组点完全相同，且所有query原本不合格。这说明有效区域采样只针对padding稀释，不解决所有极小目标问题，也不能与历史BLL标注缩小修复混为一谈。

## 机制和局限

该对照隔离了匹配采样区域变化，在固定模型输出下改善了本批小目标的采样覆盖和正样本分配稳定性。没有更换标签、GT选点、增加query或额外网络；符合先问题证据、再单因素验证的路线。

虽然三项数值权重相同，点分布变化会改变BCE/Dice成本的有效统计区域和相对量级；不能说“只增加了前景点、其他成本含义完全不变”。当前实现仅为诊断脚本，没有接入训练head，不代表完整框架已经验收。

未检查：训练早期权重、多图batch不同有效尺寸、空GT、所有辅助解码层接入、原loss及梯度稳定性、训练恢复和最终AP。没有以这些未知为由直接展开长训；本轮更新次数0、模型预测不变。

## 下一最小步骤

建议将“仅匹配点限制有效区域”准备成默认关闭的独立选项，维持原mask损失采样及其他参数不变。用少量真实训练batch检查关闭时原loss/分配一致，开启时最终层与辅助层使用各图正确有效尺寸，覆盖batch内不同尺寸、无padding和空GT，检查loss/梯度有限但不做optimizer.step。

这属于接入验收，不是正式训练授权。完成后再决定是否做固定小预算短试跑，不能从本轮分配IoU改善直接估计AP增益。不恢复BLL，不顺带加MFRM或其他模块。
