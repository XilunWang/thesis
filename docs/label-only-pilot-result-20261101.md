## 如何理解失败项

“未触及小目标支持”不是已确认背景或分割误报，其中可能包含大目标、其他已标注实例或未标注内容。本轮没有做这些归属细分，不能说新增1456个真实背景误报。

固定候选预算下三类计数守恒：

- 旧：400个新增匹配 + 3204个重复/竞争格 + 9196个未触及小目标格 = 12800。
- 新：535 + 1613 + 10652 = 12800。
- 变化：+135 −1591 +1456 = 0。

因此重复减少后，一部分名额变成了新增覆盖，其余落在小目标支持之外。不能将这个门槛失败解释为“所有效果更差”，也不能用计数解释把冻结的失败判成通过。
